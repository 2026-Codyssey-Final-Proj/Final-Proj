**`index.html`을 브라우저로 바로 연다**(설치 없음). 물범 그림은 옆 폴더의 `../navigator/seal.js`를 그대로 불러 쓴다. 시험(`*.test.js`)은 [04-tests/library/](../../04-tests/README.md)에 있다(2026-10-17 폴더 정리). 시연 입구는 [`../index.html`](../index.html).

## 어디까지가 이 시안인가 (2026-10-17 정리)

작업 화면 위 오버레이는 **내비게이터(`../navigator`) 하나**다. 이 시안에 따로 있던 위젯(지금 · 단계 지도 · 한곳에서 보기 · 도서관 탭)은 내비게이터의 **'한곳에서 보기' · '도서관' 탭**으로 옮겼다 — 같은 화면이 둘이 되지 않게([기획 확정 한 장](../../01-docs/00-overview/plan-confirm-2026-10-18.md) 4절). 여기 남은 것은 **서고**다.

| 어디 | 무엇 |
|---|---|
| 내비게이터 '도서관' 탭 | 열어 둔 책 4권 → 고르고 · 보고 · 덮고 · 세션 덮기 · 완주한 책은 **한 권으로 엮기** → 이 서고로 넘어온다(`#lib-bound-<id>`) |
| 내비게이터 '한곳에서 보기' 탭 | 진행 · 할 일 · 일정 충돌 · 토큰 (가상 숫자) — 이 폴더의 `books.js` · `schedule.js`를 읽는다 |
| **이 시안** | 입구 → 서고 → 펼친 책 · 전체 돌아보기(역량 지도) · 플로로에게 묻기 · 찾기 · 레퍼런스 서가, 그리고 지식 은하(`sky.html`) |

## 무엇을 보여 주나

| 순서 | 장면 | 할 수 있는 것 |
|---|---|---|
| 1 | 입구 — 받침대 위 큰 책 | 큰 책을 누르면 도서관 두 가지가 펼쳐진다 |
| 2 | 두 가지 고르기 | ① 작업 화면 위 위젯 → **내비게이터의 도서관 탭으로 간다** / ② 큰 기능(내 서고) |
| 3 | 플로로의 얼음 서고 | 끝낸 책이 책장에 있다. 책을 가리키면 같은 배움을 쓴 책끼리 금빛 선으로 이어진다. "← 작업 화면으로"는 내비게이터의 도서관 탭 |
| 3b | **전체 돌아보기** (오른쪽 위) | 끝낸 책 · 열어 둔 책 · 모은 책갈피 · 완주 횟수, 책마다 지나온 8단계(점), **역량 지도**(레벨 4단계 · 노력), 되풀이해 남긴 인사이트. 끝낸 책은 표지로, 열어 둔 책은 내비게이터로 |
| 4 | 서고에서 펼친 책 (먼저 **표지**: ○번째 책 · 기간 · 8단계 · 책갈피 수 · 완주 도장 — 누르면 펼침) | 단계마다 정한 것 0~7, 배운 것 · 인사이트 · 만든 것 · 이어진 책(눌러서 넘어가기) |
| 5 | 가운데 플로로에게 묻기 | "지난번엔 EARS를 어떻게 썼지?" 등 — 찾은 책을 오른쪽 카드로 펼친다. **레퍼런스 서가**도 여기서 |
| 6 | **서고에서 찾기** (위쪽 검색창, `/`로 바로) | 끝낸 책 · 열어 둔 책 · 레퍼런스를 한 번에 찾아 검색창 바로 밑에 펼친다(↑↓ · Enter). 열어 둔 책은 내비게이터로 넘어간다 |
| 7 | **엮은 책 받기** | 내비게이터에서 "한 권의 책으로 엮기"를 누르면 `#lib-bound-s3`로 와서 '숫자 · 돈' 책장에 꽂히고 표지가 열린다 |
| 8 | **내 배움** (오른쪽 위 ✎, 2026-10-18 F-05) | 내비게이터의 '내 배움' 탭을 여기로 옮겼다(PRD 2-7 "자세한건 서재로") — 지나온 단계 · 배운 말(한 줄 풀이) · 확정한 설계도. **더미가 아니라 이 브라우저에 남은 내비게이터 기록**을 `learn.js`로 읽는다. 기록이 없으면 빈 안내 |

## 지식 은하 — `sky.html`

서고 오른쪽 위 **✦ 지식 은하**로 들어간다. 세 겹으로 들어간다(이재엽 요청 2026-10-17):

| 겹 | 무엇 = 무엇 | 보이는 것 |
|---|---|---|
| 한 해 하늘 | 은하 12개 | 달마다 은하 하나 — 태양계 수 · 책 수 · 큰 태그 3개 |
| **은하** | **달 = 각자의 폴더**(`knowledge/2026-10/`) | 태양계(태그)마다 빛깔 성운과 별자리, 같은 책이 두 태그를 가지면 태양계 사이에 금빛 점선 다리. 오른쪽에 태양계 목록과 모든 은하의 태그 |
| **태양계** | **태그 하나**(지식 파일의 첫 태그) | 해(태그 이름)에서 가지처럼 갈라지는 별자리, 별마다 제목 · 이해 수준. 다른 태그가 첫 태그인 책은 "손님"으로 목록에 |
| 별 | 책 한 권 = GitHub 지식 파일 하나 | 📍 "10월 은하 · 보안 태양계 ★2", GitHub 경로 · 커밋, 다른 은하의 같은 태양계 |

별자리는 정해 둔 12궁 모양이 아니라 **가장 짧은 선으로 잇는 가지 모양**이라 별 수에 상한이 없고, 같은 파일이면 언제나 같은 모양이다.
별의 밝기 · 크기 = 이해 수준(처음 봄 … 응용함), 직접 씀부터 십자 빛, 응용함은 금빛. **#태그**를 누르면 모든 은하에서 그 태그의 책을 은하 순서로 본다.
주소 끝: `sky.html#year` · `#m10` · `#m10/보안` · `#m10/보안/2` · `#tag=보안` · `#q=EARS`. Esc는 한 겹씩 위로. 설계: [`knowledge-sky-github.md`](../../01-docs/04-pattern-implementation/knowledge-sky-github.md)

## 주소로 장면 바로 열기 (시연·녹화용)

`index.html#hall` · `#pick` · `#lib` · `#lib-review`(전체 돌아보기) · `#lib-hover`(금빛 선) · `#lib-f1`(표지부터) · `#lib-open-f1`(표지 없이 펼침) · `#lib-ask`(플로로 답) · `#lib-q=EARS`(검색 결과) · `#lib-bound-s3`(내비게이터에서 엮은 책 받기) · `#lib-dive`(내비게이터의 '내 서고 들어가기' — 물속에서 떠오르고 플로로가 점프, `../navigator/dive.js`) · `#lib-learn`(내 배움) · `#lib-dive-learn`(물속으로 들어온 뒤 내 배움 — 내비게이터의 "서재에서 자세히 보기").
책장의 책을 누르면 가운데로 날아와 크게 보이고, 표지를 누르면 책등을 축으로 넘어가며 펼쳐진다(2026-10-18, 목업 영상 40~42초).
옛 주소 `#desk…`는 내비게이터의 도서관 탭으로 넘어간다. [3분 시연 스토리](../../01-docs/04-pattern-implementation/demo-story-3min.md)의 장면은 위 주소로 연다(시연 길잡이 띠는 2026-10-19에 지움).

## 파일

| 파일 | 무엇 |
|---|---|
| `index.html` | 장면 구조 — 입구 · 서고 · 펼친 책 · 전체 돌아보기 |
| `library.css` | 모양 — 목업 영상의 남색 밤하늘 · 아치 · 리퀴드 글래스. 위젯 규칙은 `../navigator/library-tab.css`로 옮김 |
| `library.js` | 동작 — 상태는 화면 안에서만 바뀐다(새로 고침하면 처음으로). `#lib-bound-<id>`로 엮은 책을 받는다 |
| `books.js` | 더미 데이터 — 열어 둔 책 4권, 끝낸 책 5권, 레퍼런스 4개, 플로로에게 물을 것 3개, 캘린더 · 토큰 가상 값. **내비게이터의 도서관 · 한곳에서 보기 탭도 이 파일을 읽는다** |
| `schedule.js` | 마감 계산 — 남은 날 · 알림 3시점 · 팀 일정 핀과 부딪침 · 일정 충돌 (순수 함수). 내비게이터의 두 탭이 쓴다 |
| `skills.js` | FR-8 역량 지도 — 배운 것마다 레벨 4단계 · 노력(책 수 · 날 수). 레벨 규칙은 가설(끝낸 책 1권 이해함 · 2권 직접 씀 · 3권+ 응용함), 시험 3개 |
| `search.js` | 서고 검색 — 화면과 떨어진 순수 함수. 표지에 있는 글만 찾고 본문은 색인하지 않는다 |
| `spotlight.js` | 검색창 바로 밑에 결과를 펼치는 부품(↑↓ · Enter · Esc) — 서고와 하늘이 같이 쓴다 |
| `learn.js` | 내 배움이 읽는 기록 — 내비게이터가 이 브라우저(localStorage)에 남긴 지나온 단계 · 배운 말 · 확정한 설계도. 고장 난 기록이면 빈 배움(순수 함수, 시험 `learn.test.js`). 배운 말의 풀이는 `../../03-backend/navigator/glossary.js` |
| `sky.html` · `sky.css` · `sky.js` | 지식 은하 |
| `knowledge-sky.js` | GitHub 지식 파일(머리말) → 은하(달 폴더) · 태양계(태그) · 별. 가지 모양 별자리 · 태그로 책 보기 · "어디에 있어요?" |
| `sky-data.js` | 더미 지식 파일 40개 + 아직 안 가져온 2개(예시 저장소 `my-id/my-knowledge`) |
| (시험) | `../../04-tests/library/` — 마감 계산 10개 · 역량 지도 3개 · 검색 8개 · 하늘 12개 · 내 배움 기록 6개. `python 04-tests/run_all_tests.py`가 노드 시험까지 같이 돌린다 |

## 아직 아닌 것

- 서고 · 하늘의 책과 별은 더미다 — 두 화면 머리에 **"예시 데이터예요 · 시연용"**을 보인다(2026-10-18 F-17, 원칙 P7). 내 배움만 이 브라우저의 실제 기록이다.
- 실제 세션·저장소를 읽지 않는다. 내비게이터에서 "세션 덮기"한 책은 그 화면 안에서만 사라진다(이 서고의 책장에는 더하지 않는다 — 엮은 책만 받는다).
- 플로로의 답은 `books.js`의 표에서만 찾는다(AI를 부르지 않고, 지어내지 않는다).
