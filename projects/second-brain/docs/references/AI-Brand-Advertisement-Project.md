## 목적 연결

- **1단계 기대 동작 "발표 자료와 과제 결과물 디자인"** — 결과물의 톤을 맞추고 비싼 생성 전에 검토하는 방법. 연결은
  약한 편이라 사용자가 "넣는다"(가)로 정했다(2026-10-01).

## 가져올 것 (후보)

| 단계 | 재료 | 쓰는 곳 |
|---|---|---|
| 디자인 결과물 | 모든 장면에 공통 스타일 키워드를 고정해 톤 통일 | theme-factory 테마 고르기와 같은 원칙 — 발표 자료 한 벌에 테마 하나 |
| 디자인 결과물 | **스토리보드를 먼저 확정하고 이미지를 충분히 검토한 뒤 영상으로** — 비싼 단계 전에 싼 단계에서 고친다 | 발표 자료: 개요 → 시안 → 완성 순서 |
| 디자인 결과물 | 장면 프롬프트 구조(카메라 구도·조명·스타일·제품 중심을 구체적으로) | canvas-design으로 포스터·표지를 만들 때 요청 문장 |

## 교훈

- 사용자 진술: "좋은 결과물은 좋은 AI에서 나오는 것이 아니라, 좋은 기획과 좋은 프롬프트에서 시작된다."
- 영상 생성에서 크레딧이 많이 들었다 — 지금은 유료 도구를 쓰지 않는다(Motion 제외와 같은 이유).
