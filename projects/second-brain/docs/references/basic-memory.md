## 무엇

- [basicmachines-co/basic-memory](https://github.com/basicmachines-co/basic-memory) — AI가 대화를 넘어 기억하게 하는
  **MCP 서버**. 지식을 디스크의 마크다운 파일로 저장하고, Claude가 MCP 도구로 읽고 쓴다. 사람도 같은 파일을 직접 고친다
  (Obsidian과 같은 폴더를 쓸 수 있다). AGPL-3.0.
- 로컬은 무료(Python·uv 필요). 웹·휴대폰·동기화·백업이 되는 클라우드는 월 $15.
- 처음 본 곳: 인스타그램(사용자). 내용은 공식 저장소 README로 확인했다. 기준: 2026-10-06 `main`.

## 목적 연결

- **P1 지식 사이클 — 가장 직접적.** F1(넣으면 요약)·F3(마크다운 창고에 저장)·F7(진행 중인 프로젝트를 기억하고 말해 준다)을
  도구 하나가 겨냥한다.
- **P3 MCP·스킬** — 들이려면 [external-integration.md](../../../../.claude/rules/external-integration.md) "MCP 서버를 들일 때" 점검표를 거친다.

## 가져올 것 (후보)

| 단계 | 재료 | 쓰는 곳 |
|---|---|---|
| 3단계 저장 구조 | 노트 한 장 = **관찰**(분류가 붙은 사실) + **관계**(위키 링크) | F10 "관찰 → 해석 → 행동" 형식, F9 지식 그래프와 비교. 링크가 곧 그래프라 따로 그래프 DB를 두지 않는다 |
| 3단계 저장 구조 | 사람과 AI가 **같은 마크다운 파일**을 고친다 | 이미 정한 "마크다운 파일 + GitHub 비공개"와 같은 방향 — 직접 만들기 대신 이 도구를 쓰는 안을 ADR 대안으로 |
| 3단계 도구 설계 | 도구마다 읽기 전용·파괴적·멱등 힌트를 붙인다 | 세컨드 브레인이 MCP나 명령을 만들게 되면 같은 구분을 쓴다 |
| 6단계 보안 점검 | `delete_note`·`move_note` 같은 되돌리기 어려운 도구 | 들이면 `settings.json` deny 후보 — 반영구 보관(지우지 않는다, 2026-10-04)과도 맞춘다 |

## 교훈

- **기억 장소가 세 갈래가 될 위험.** Claude Code 메모리 폴더, 저장소의 규칙·장부, Basic Memory 노트에 같은 사실이 따로
  적히면 어긋난다(후보 장부가 커밋과 어긋난 2026-10-04 사례와 같은 문제). 들인다면 "무엇을 어디에 적나"를 먼저 정한다.
- 휴대폰(F11)은 유료 클라우드에서만 된다 — 로컬로 진행하면 휴대폰은 지금 결정(GitHub 앱으로 파일 고치기)에 맡긴다.

## 보안 메모

- 공개 오픈소스. 로컬로 쓰면 노트는 내 디스크에 남지만, Claude가 읽은 내용은 AI 서비스로 전송된다
  ([기록·보안 기준](../../../../.claude/rules/security-records.md) 1절).
- 세컨드 브레인 전체 결정(사용자 2026-10-06): **지금은 로컬, 나중에 서버에 올린다.** 클라우드 판(유료)은 쓰지 않는다 — 서버로 옮길 때는 직접 띄우는 쪽이다.
