## 목적 연결

- **P1 지식 사이클** — 인사이트를 **관찰(Fact) → 해석(가설) → 행동(Action)** 구조로 썼다. 자료가 "다음 판단의
  기준"으로 돌아가는 형식이 이미 있다.
- **P2 진행 방식** — "브랜치 → PR → 사용자 직접 병합", PRD 먼저 정리, CI로 재현성 확인. 지금 워크스페이스 방식과 같다.

## 교훈

- manyfast의 세부 요구사항 기능이 유료(PRO)라 **같은 구조를 로컬 문서로 대체**했다 — 유료 도구 대신 구조만 가져오는
  습관.
