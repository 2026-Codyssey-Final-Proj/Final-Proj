**`index.html`을 브라우저로 바로 연다**(설치 없음). 물범 그림은 옆 폴더의 `../navigator-prototype/seal.js`를 그대로 불러 쓴다.

## 무엇을 보여 주나

| 순서 | 장면 | 할 수 있는 것 |
|---|---|---|
| 1 | 입구 — 받침대 위 큰 책 | 큰 책을 누르면 시안 두 가지가 펼쳐진다 |
| 2 | 시안 고르기 | ① 작은 기능(오버레이 위젯) / ② 큰 기능(내 서고) |
| 3 | 작업 화면 위 오버레이 — **도서관** 탭 | 열어 둔 책(세션) 4권 중 하나를 고른다 |
| 4 | 위젯 안의 펼친 책 | 이 세션에서 정한 것 · 꽂은 책갈피를 본다 → **책 덮기**(Esc) 또는 **세션 덮기**(확인 뒤 Enter, 서고에 꽂힘) |
| 5 | 플로로의 얼음 서고 | 끝낸 책이 책장에 있다. 책을 가리키면 같은 배움을 쓴 책끼리 금빛 선으로 이어진다 |
| 6 | 서고에서 펼친 책 | 단계마다 정한 것 0~7, 배운 것 · 인사이트 · 만든 것 · 이어진 책(눌러서 넘어가기) |
| 7 | 가운데 플로로에게 묻기 | "지난번엔 EARS를 어떻게 썼지?" 등 — 찾은 책을 오른쪽 카드로 펼친다. **레퍼런스 서가**도 여기서 |
| 8 | **서고에서 찾기** (위쪽 검색창, `/`로 바로) | 끝낸 책(이름·배운 것·단계마다 정한 것·인사이트·만든 파일) · 열어 둔 책(정한 것·책갈피) · 레퍼런스를 한 번에 찾는다. 띄어 쓴 낱말은 모두 들어 있는 곳만, 대소문자 구분 없음. 찾은 책은 책장에서 빛나고, 결과를 누르면 끝낸 책은 서고에서 · 열어 둔 책은 위젯에서 펼친다. Esc로 지운다 |

## 주소로 장면 바로 열기 (시연·녹화용)

`index.html#hall` · `#pick` · `#desk` · `#desk-s3`(위젯에서 가계부 위젯 펼침) · `#lib` · `#lib-hover`(금빛 선) · `#lib-f1`(서고에서 책 펼침) · `#lib-ask`(플로로 답) · `#lib-q=EARS`(검색 결과)

## 파일

| 파일 | 무엇 |
|---|---|
| `index.html` | 장면 구조 |
| `library.css` | 모양 — 목업 영상의 남색 밤하늘 · 아치 · 리퀴드 글래스 |
| `library.js` | 동작 — 상태는 화면 안에서만 바뀐다(새로 고침하면 처음으로) |
| `search.js` | 서고 검색 — 화면과 떨어진 순수 함수. 표지에 있는 글만 찾고 본문은 색인하지 않는다 |
| `search.test.js` | 검색 시험 8개 — `node --test`로 돌린다(저장소의 `run_all_tests.py`는 파이썬 시험만 돈다) |
| `books.js` | 더미 데이터 — 열어 둔 책 4권, 끝낸 책 5권, 레퍼런스 4개, 플로로에게 물을 것 3개 |

## 아직 아닌 것

- 실제 세션·저장소를 읽지 않는다. "세션 덮기"는 화면 안에서만 책을 옮긴다.
- 플로로의 답은 `books.js`의 표에서만 찾는다(AI를 부르지 않고, 지어내지 않는다).
- 프로토타입(`navigator-prototype`)의 탭에는 아직 붙이지 않았다 — 붙이는 방법은 구현 담당이 정한다.
