## 무엇을 보여 주나

| 순서 | 장면 | 할 수 있는 것 |
|---|---|---|
| 1 | 입구 — 받침대 위 큰 책 | 큰 책을 누르면 시안 두 가지가 펼쳐진다 |
| 2 | 시안 고르기 | ① 작은 기능(오버레이 위젯) / ② 큰 기능(내 서고) |
| 3a | 오버레이 **지금** 탭 | 프로젝트마다 지금 단계 · **마감 칩**(여유 / 3일 이내 / 오늘 / ❄ 지남) · 할 일 체크 · 알림 3시점(3일 전 · 1일 전 · 당일 8시, 지난 것은 줄 긋기). **Claude 작업 끝남 (시연)** 을 누르면 다음 할 일이 끝남으로 표시되고(FR-7), 다 하면 플로로가 도장을 찍는다 |
| 3b | 오버레이 **단계 지도** 탭 | 0 생각하기 → 7 돌아보기, 단계마다 마감 날짜, 오늘 위치에 플로로, 늦은 단계는 빨간 고리. 아래에 팀 일정 핀(11/1 기능 동결 · 11/8 제출)과 "동결 뒤에 끝나는 단계" 경고. 7단계까지 끝나면 돌아보기(0~7단계에 정한 것 · 인사이트) |
| 3d | 오버레이 **한곳에서 보기** 탭 (FR-6) | 진행 상황(프로젝트마다 8단계 점 · 마감) · 내가 할 일(마감 가까운 순) · **일정 충돌**(같은 날 마감 / 캘린더 일정과 겹침 / 팀 기능 동결 뒤) · 토큰 사용(예산 통 4개). 모두 **가상 숫자** 표시. 프로젝트를 누르면 단계 지도로 — 옮길지는 사람이 정한다 |
| 3c | 책으로 엮기 | 완주한 프로젝트(시안: 가계부 위젯)는 "한 권의 책으로 엮을까요?" → 종이가 모여 책이 되고 서고 책장에 꽂혀 표지가 열린다 |
| 3 | 작업 화면 위 오버레이 — **도서관** 탭 | 열어 둔 책(세션) 4권 중 하나를 고른다 |
| 4 | 위젯 안의 펼친 책 | 이 세션에서 정한 것 · 꽂은 책갈피를 본다 → **책 덮기**(Esc) 또는 **세션 덮기**(확인 뒤 Enter, 서고에 꽂힘) |
| 5 | 플로로의 얼음 서고 | 끝낸 책이 책장에 있다. 책을 가리키면 같은 배움을 쓴 책끼리 금빛 선으로 이어진다 |
| 5b | **전체 돌아보기** (서고 오른쪽 위) | 끝낸 책 · 열어 둔 책 · 모은 책갈피 · 완주 횟수, 책마다 지나온 8단계(점), 자주 꺼내 쓴 배움, 되풀이해 남긴 인사이트. 줄을 누르면 끝낸 책은 표지로 · 열어 둔 책은 단계 지도로 |
| 6 | 서고에서 펼친 책 (먼저 **표지**: ○번째 책 · 기간 · 8단계 · 책갈피 수 · 완주 도장 — 누르면 펼침) | 단계마다 정한 것 0~7, 배운 것 · 인사이트 · 만든 것 · 이어진 책(눌러서 넘어가기) |
| 7 | 가운데 플로로에게 묻기 | "지난번엔 EARS를 어떻게 썼지?" 등 — 찾은 책을 오른쪽 카드로 펼친다. **레퍼런스 서가**도 여기서 |
| 8 | **서고에서 찾기** (위쪽 검색창, `/`로 바로) | 끝낸 책(이름·배운 것·단계마다 정한 것·인사이트·만든 파일) · 열어 둔 책(정한 것·책갈피) · 레퍼런스를 한 번에 찾아 **검색창 바로 밑에** 펼친다(↑↓로 고르고 Enter로 펼침, 오른쪽에 "서고 › 기록 · 폼 책장"처럼 어디인지). 띄어 쓴 낱말은 모두 들어 있는 곳만, 대소문자 구분 없음. 찾은 책은 책장에서 빛나고, 결과를 누르면 끝낸 책은 서고에서 · 열어 둔 책은 위젯에서 펼친다. Esc로 지운다 |

## 지식 별자리 하늘 — `sky.html`

서고 오른쪽 위 **✦ 별자리 하늘**로 들어간다. 지식 한 개 = GitHub 지식 파일 한 개 = 별 한 개. 1월~12월 별자리(황도 12궁)마다 "무슨 이야기"인지와
"10월 천칭자리 ★2 · 저울대 가운데"처럼 어디에 있는지를 보인다. GitHub 칸의 **새 지식 가져오기**, 한 해 하늘, 검색창 밑 결과, ←→로 달 넘기기.
주소 끝: `sky.html#m10` · `#m10-2` · `#year` · `#q=EARS`. 설계: [`knowledge-sky-github.md`](../../docs/04-pattern-implementation/knowledge-sky-github.md)

## Must 요구사항 — 어디서 되는가 (requirements.md 10절, 2026-10-17 대조)
