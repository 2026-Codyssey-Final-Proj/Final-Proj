# 05-projects — 팀 제품 밖의 프로젝트

**이 폴더는:** Floe(팀 제품)가 아닌 프로젝트를 따로 두는 곳이다. Floe의 코드는 `02-frontend/`·`03-backend/`, 시험은 `04-tests/`에 있다.

## 안에 뭐가 있나

| 폴더 | 무엇 | 누구 |
|---|---|---|
| [`second-brain/`](second-brain/README.md) | 세컨드 브레인 — 지식 창고 + 마감 알림. 이재엽 님의 개인 프로젝트(V1)를 옮겨 와 여기서 마무리한다 | 이재엽 |

- Floe와 합치는 일은 대회 뒤로 정했다(구조 결정 기록 ADR-0006).
- 각 프로젝트는 자기 안에 문서(`docs/`)·코드·시험(`implementations/`)을 따로 갖는다. 시험은 `04-tests/run_all_tests.py`가 같이 돌린다.
- 개인 데이터(할 일 원문 등)는 이 저장소에 두지 않는다.

## 처음이면

세컨드 브레인을 볼 일이 없다면 이 폴더는 건너뛰어도 된다. 보려면 [second-brain/README.md](second-brain/README.md)부터.
