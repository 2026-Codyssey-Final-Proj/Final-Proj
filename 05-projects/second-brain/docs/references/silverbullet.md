## 무엇

- [silverbulletmd/silverbullet](https://github.com/silverbulletmd/silverbullet) — 내 서버에 올려 브라우저로 쓰는
  **마크다운 노트 앱**. 노트는 폴더 안의 마크다운 파일이고, 위키 링크·질의 언어(SLIQ)·템플릿·Lua 스크립트로 노트를
  데이터베이스처럼 쓴다. 오프라인에서도 열린다. MIT.
- 서버는 Docker 이미지로 띄운다. AI·MCP 연동은 문서에 없다.
- 처음 본 곳: 인스타그램(사용자). 내용은 공식 저장소와 [silverbullet.md](https://silverbullet.md/)로 확인했다. 기준: 2026-10-06.

## 목적 연결

- **P1 지식 사이클 — 사람 쪽 화면.** F4(검색)·F6(한곳에서 보는 화면)·F13(태그)에 닿는다.
- **P2 프로젝트 진행** — 질의로 "기한이 남은 할 일" 같은 목록을 만들면 F8(남은 날)의 화면 쪽 후보.

## 가져올 것 (후보)

| 단계 | 재료 | 쓰는 곳 |
|---|---|---|
| 3단계 저장 구조 | 노트의 머리말·태그·할 일을 **질의할 수 있는 객체**로 본다 | 항목 머리말 필드(My-Prompt-Manager 4필드와 비교)를 정할 때 "나중에 무엇으로 묶어 볼지"부터 정한다 |
| 3단계 화면 설계 | 질의 결과를 노트 안에 붙이는 화면(대시보드 노트) | F6 화면을 따로 만들지, 노트 안 질의로 대신할지 ADR 대안 |
| 4단계 | 같은 마크다운 폴더를 여는 편집기 | 직접 만든 기능과 함께 쓸 수 있는지 — Claude Code는 파일을, 사람은 이 화면을 |
| 6단계 보안 점검 | 서버를 띄우면 인증이 필요하다 | S6 — 로컬(이 컴퓨터만)에 두면 밖에 공개하지 않는다 |

## 교훈

- 파일이 원천이고 앱은 화면일 뿐이라, 앱을 바꿔도 지식은 남는다 — 마크다운 파일로 정한 이유와 같다.
- 휴대폰에서 쓰려면 서버를 계속 켜 두고 밖에서 접속해야 한다. 지금은 로컬이라 휴대폰은 GitHub 앱에 맡기고, 나중에 서버에 올리면(사용자 2026-10-06) 이 도구가 휴대폰 화면 후보가 된다 — 그때 S6 인증이 먼저다.

## 보안 메모

- 공개 오픈소스, 외부 전송 없음(AI 연동 없음). 로컬에서만 띄우면 S4(밖으로 보내지 않는다)와 충돌하지 않는다.
