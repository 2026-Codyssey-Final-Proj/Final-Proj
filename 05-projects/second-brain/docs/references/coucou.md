## ② 문서화 — 원칙만 (README·코드에서 확인한 사실)

- **연결 방식:** Claude Code 훅(`PermissionRequest` 등)이 작은 스크립트로 이벤트를 앱에 넘긴다. 앱이 꺼져 있으면 훅은 바로 끝나서 **에이전트를 막지 않는다**.
- **설치:** `~/.claude/settings.json`을 **날짜 붙은 백업을 만든 뒤**, 합칠 훅의 **diff를 보여 주고** 쓴다.
- **"Always" 버튼:** Claude Code가 내놓은 권한 제안(`permission_suggestions`)을 `updatedPermissions`로 돌려준다 — 즉 **영구 허용 규칙이 Claude Code 설정에 쌓인다**(`HookServer.swift`).
- **폰 승인:**
  - Allow에만 Face ID(iPhone)·지문(Android)을 요구하고 Deny는 바로 된다.
  - **폰에서는 Allow / Deny만** 있고 "Always"는 없다.
  - 결정은 **기다리는 요청과 지문(세션·도구·명령·입력)이 같을 때만** 적용하고, 늦게 온 결정이나 다른 명령용 결정은 버린다. 처리가 끝나면 요청 기록을 지운다(`ApprovalRelay.swift`).
  - 명령이 너무 길어 폰에 다 보이지 않으면 Allow는 컴퓨터에서만 된다(Android).
- **밖으로 나가는 것:** iPhone 연동은 세션을 내 iCloud(CloudKit)에 올린다(민감 칸 암호화). 잠금 화면 알림은 Cloudflare 중계를 거치고, 중계는 **에이전트 이름과 상태만** 본다. 채팅·서비스 알림·음성 명령은 각자의 API 키. 사용 기록(analytics)은 없다고 적혀 있다.
- **그 밖:** 데모 모드는 디스크에 아무것도 쓰지 않는다. 매주 월요일 로컬 통계(공유 이미지에서 프로젝트 이름은 선택).

| 새 재료 | 목적지 | 왜 새로운가 |
|---|---|---|
| **위험한 쪽만 확인을 강하게** — 허용(되돌리기 어려움)에는 본인 확인, 거절은 바로. 멀리서는 영구 허용을 만들 수 없게 | 워크스페이스 → 장부 **W-25** | 우리 확인 규칙은 "확인한다/안 한다"뿐이고, 결과의 무게에 따라 확인 강도를 나누는 기준이 없다 |

## 작업할 때 어떻게 하나

### 1. 도구 자체 — 지금은 설치하지 않는다

외부 도구 후보 표에 "후보"로 두고, 아래 **꺼낼 신호**가 생기면 Claude가 그 행을 꺼내 제안한다.

- 꺼낼 신호: 자리를 비운 채 긴 Claude Code 작업을 폰으로 지켜보거나, 권한 요청에 폰으로 답하고 싶을 때.
- 지금 들이지 않는 이유: 2주 된 앱이라 변화가 빠르고, 사용자 결정 "개인 정보를 밖으로 보내는 도구는 쓰지 않는다"와 iPhone 연동(iCloud·중계 서버)을 맞대 봐야 한다.

**들이기로 하면** — `dev-workflow` 명령 4([external-integration.md](../../../../.claude/rules/external-integration.md)) 절차에 더해 이 도구에서 꼭 볼 것:

1. **설치 전:** `~/.claude/settings.json`을 직접 한 번 더 백업하고, coucou가 보여 주는 diff를 사용자가 읽고 승인한다(규칙 2번).
2. **설치 후 위반 시도:** 우리 훅이 여전히 막는지 직접 시험한다 — 가짜 키를 넣은 커밋이 `check-secrets.sh`에 막히는지, `git push --force`가 막히는지. 자동 테스트와 사람이 해 본 것을 따로 적는다(기록·보안 기준 6-2).
3. **"Always"는 누르지 않는다.** 영구 허용 규칙이 Claude Code 설정에 쌓인다. 눌렀다면 어느 설정 파일에 무슨 규칙이 생겼는지 확인하고 기록한다.
4. **iPhone 연동은 끈 채로 시작한다.** 켜면 기록·보안 기준 3절에 행을 더한다(iCloud CloudKit, Cloudflare 중계 — 에이전트 이름·상태).
5. **채팅·서비스 알림·음성 명령은 쓰지 않는다**(API 키와 외부 전송). 쓰기로 하면 3절에 행을 더한다.
6. **버전을 적어 둔다.** 월말 정리(외부 도구 후보 표) 때 라이선스·전송·설치 방식이 바뀌었는지 다시 본다.

### 2. 도구 없이 지금 쓸 수 있는 것

- **W-25~W-27 판정** — 채택되면 기록·보안 기준 6-3(W-25·W-26)과 루트 `CLAUDE.md` 훅 표(W-27)에 넣는다. 판정은 사용자가 한다.
- **세컨드 브레인에서:** 폰으로 무언가를 승인하는 기능이 생기면(지금 UC6은 세션 안에서 "예"를 받는다) W-25·W-26을 그 기능의 요구 후보로 꺼낸다. UC11을 만들 때 "공유 시 이름 빼기"를 선택지로 본다.
