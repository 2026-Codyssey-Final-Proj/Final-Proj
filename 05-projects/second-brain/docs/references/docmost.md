## 무엇

- [docmost/docmost](https://github.com/docmost/docmost) — Notion·Confluence를 대신하는 **팀용 위키**. 실시간 공동 편집,
  댓글, 페이지 이력, 권한·그룹·스페이스, draw.io·Excalidraw·Mermaid 그림. 본체는 AGPL-3.0, 일부 기능은 유료 기업용 라이선스.
- 내용은 마크다운 파일이 아니라 **DB**에 저장된다 — `docker-compose.yml`이 앱 + PostgreSQL + Redis 세 개를 띄운다.
- 공식 [MCP](https://docmost.com/docs/user-guide/mcp)는 유료 라이선스 기능이다. 일반 REST API는 무료 판에도 있다.
- 처음 본 곳: 인스타그램(사용자). 내용은 공식 저장소·문서로 확인했다. 기준: 2026-10-06.

## 목적 연결

- **약함.** 세컨드 브레인은 개인용이고 팀원 정보는 이름·직책·한 줄만 둔다(S3) — 팀 기능이 핵심인 도구라 쓸 곳이 적다.
- 굳이 닿는 곳은 **P2 프로젝트 진행**(팀 과제 문서를 함께 쓸 때)이다.

## 가져올 것 (후보)

| 단계 | 재료 | 쓰는 곳 |
|---|---|---|
| 3단계 저장 구조 | "DB에 저장 + 마크다운으로 내보내기" 방식 | "마크다운 파일이 원천" 결정의 **버린 대안**으로 ADR에 적을 재료 — 왜 안 쓰는지 근거가 된다 |
| 3단계 (팀 과제) | 페이지 이력·권한·스페이스 | 나중에 팀 과제 문서를 같이 쓸 일이 생기면 다시 본다 |

## 교훈

- 서버 세 개를 운영해야 하고, 지식이 DB 안에 있어 git으로 이력을 볼 수 없다 — 반영구 보관(2026-10-04)과 백업(5절 빈칸)이
  더 어려워진다.
- AI 연동(MCP)이 유료라 "유료면 안 쓴다"와 부딪힌다.

## 보안 메모

- 공개 오픈소스. 로컬로 띄우면 밖으로 나가는 것은 없다(세컨드 브레인 전체 결정 2026-10-06: 지금은 로컬, 나중에 서버). 팀원 정보가 들어가는 도구라 쓰게 되면
  [기록·보안 기준](../../../../.claude/rules/security-records.md) 4절을 다시 본다.
