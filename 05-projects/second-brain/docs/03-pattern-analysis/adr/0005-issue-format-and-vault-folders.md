# ADR-0005: 이슈 제목 틀과 창고 폴더 — `목적 / 이름 / 내용 / 마감`

- Status: **Accepted** — 창고 폴더 모양은 [ADR-0006](0006-serial-numbers.md)이 대체(이슈 제목 틀·알림 제목은 그대로)
- Deciders: 사용자 (2026-10-08, "1: 가 / 2 : 예")
- Date: 2026-10-08
- 대체하는 것: [ADR-0004](0004-vault-location-and-layout.md)의 **폴더 모양**(`<프로젝트>/<할 일>`)과 세션 파일 D2·D3·D6의 **이슈 틀·알람 한 줄**. 창고 위치(이 저장소 안 `projects/second-brain/vault/`)는 그대로다.

## Context and Problem Statement

첫 실제 시험(이슈 #55·#56, 2026-10-08)에서 두 가지가 드러났다. (1) 사용자가 쓰기 쉬운 틀은 `프로젝트 / 할 일 / 기한`이 아니라 **목적(분류) / 이름 / 내용 / 마감**이다. (2) 알람 제목의 `D-22`는 일정을 만든 날 기준이라 알림이 울릴 때 틀린다.

## Considered Options

알람 제목에 관해 사용자가 두 가지 중에서 골랐다.

1. `목적 / 이름 / 10/30까지` — 목적·이름·마감일. D-N 없음. **(채택)**
2. `세컨드 브레인 / 목적/이름 / 10/30까지` — 출처 표시와 위치를 남기고 D-N만 뺀다.

## Decision Outcome

| 칸 | 규칙 |
|---|---|
| 이슈 제목(새 일) | `목적 / 이름 / 내용 / 마감` — 목적은 생활·학교·작업·대회·기타 중 하나(그 밖은 거부). 내용에는 `/`가 들어가도 되고, 앞 두 칸과 마지막 칸으로 나눈다 |
| 완료 | `완료 / 목적 / 이름` |
| 수정 | `수정 / 목적 / 이름 / 새 마감` |
| 창고 | `projects/second-brain/vault/<목적>/<이름>.md` — 내용은 문서 본문에만 들어간다 |
| 알람 제목 | `목적 / 이름 / 10/30까지` — 내용·메모는 알림에 넣지 않는다(D2) |

## Consequences

- D-N을 뺐으므로 알림 때 제목이 틀어지지 않는다. 대신 알림만 보고 "며칠 남았는지"는 알림이 울린 시점(3일 전·1일 전·당일)이 말해 준다.
- ADR-0004의 "위치"(파일 경로)가 제목에서 빠졌다. 문서를 찾으려면 `목적/이름`으로 창고를 본다.
- 이름은 목적 폴더 안에서 겹치지 않아야 한다 — 겹치면 같은 할 일로 보고 새로 만들기를 거부한다(D5).
- 코드(`intake.py`)와 테스트 18개, 추적표 F11, UC6이 이 틀로 바뀌었다.
