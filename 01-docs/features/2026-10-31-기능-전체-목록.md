# Floe 기능 전체 목록 — MECE (2026-10-31)

> **한 줄로:** 지금 앱(11.0.0)에 **있는 기능 81개**를 사용자가 만나는 자리 여덟 묶음(가 ~ 아)으로 나눠 적고, **뺀 · 숨긴 · 안 만든 것 20개**(자)와 **앱 밖 개발 도구 9개**(차)를 따로 뒀다. 한 기능은 한 묶음에만 있다.
> 우선순위(중요도 · 재사용성 · 코드 복잡도)는 짝 문서 [기능 우선순위](2026-10-31-기능-우선순위.md)에 있다.
> 요구별 상태(만듦 · 일부 · 뺌)는 [기능 현황 — 요구별](2026-10-30-기능-현황.md)(10/30)이 원천이고, 이 문서는 그것을 **기능 단위로 다시 묶은 것**이다. 10/30 뒤 바뀐 것(퀘스트 탭 합치기 #297 ~ #299 · 미뤘던 넷 #300 · 앱 11.0.0 #302)은 여기에 들어 있다.

## 0. 어떻게 나눴나

**MECE 기준 — 사용자가 그 기능을 만나는 자리.** 같은 기능이 여러 화면에 보여도 **처음 만나는 자리 하나**에만 적고, 다른 자리에서는 번호로 가리킨다.

| 묶음 | 자리 | 수 |
|---|---|---|
| **가** | 앱 껍데기 · 켜기 · 설정 — 앱을 켜고, 처음 설정하고, 폴더를 잇고, 설정 창 | 10 |
| **나** | 섬 — 플로로와 대화하는 칸(채팅 · 칩 · 카드 · 알약) | 13 |
| **다** | 작업실 — 세 칸과 탭(퀘스트 · 책 · 파일 — 캔버스 탭은 2026-11-02에 뺌) | 11 |
| **라** | 퀘스트 한 바퀴 — 단계 판정 · 초안 · 확인 · 관문 · 버전(화면이 아니라 **흐름**) | 13 |
| **마** | 일 넘기기 · Claude Code 연동 — 계획 · 맡기기 · 허락 · 보고 · 훅 | 8 |
| **바** | 지식 · 기록 — 단계 문서 · 한 장 · 가져가기 · 원본 폴더 · 보안 | 9 |
| **사** | AI 연결 · 안전 — 창구 하나 · 연습 · 녹화 · 토큰 · 가리기 · 서버 | 9 |
| **아** | 디자인 · 쉬운 말 · 움직임 — 앱 전체에 걸리는 규칙 | 7 |
| **자** | 뺀 것 · 숨긴 것 · 안 만든 것 — "없다"를 분명히 하기 위해 | 20 |
| **차** | 앱 밖 — 레포 · 개발 도구(제품 기능이 아니다) | 9 |

**칸 뜻.** `무엇을 하나` — 쉬운 말 한 줄. `어디서` — 사용자가 어디를 눌러 닿나. `요구` — [요구서](../00-overview/requirements.md)의 FR · C 번호. `코드` — 고칠 때 열 파일(괄호 안은 줄 수, 2026-10-31에 `wc -l`로 잼). `시험` — `04-tests/navigator/*.test.js`는 이름만, `e2e/`는 앞에 e2e. `상태` — **만듦**(코드에 길이 있고 시험이나 화면에 닿음) · **일부** · **숨김** · **길 없음**(코드는 있으나 가는 단추가 없음).

## 확인 못 한 것

- **앱을 켜서 사람이 눌러 본 것은 아니다.** 10/30 밤 데스크톱 앱 창(win.html)에서 퀘스트 탭 셋 · 띠 · 내림 · 흐름 가득을 CDP로 본 것(다-04)과, Chrome(puppeteer)으로 찍은 e2e 사진이 있을 뿐이다. 수용 테스트 기록표(결정 모음 B-07)는 11/3.
- **Mac · 다크 모드 · 1024 화면 · 섬을 왼쪽에 붙인 모습**은 보지 않았다(이 컴퓨터는 Windows 11).
- **진짜 Claude Code · 진짜 GitHub 저장소로 끝까지** — 허락 카드(나-09) · 맡기기(마-02) · 문서 올리기(바-01)는 연습 · 녹화 답으로만 확인했다. 진짜 AI로 1 ~ 3단계 한 바퀴를 돈 기록은 10/30 `01-docs/07-maintenance`에 있다.
- **전체 시험**은 2026-10-31에 돌렸다 — 1,155개 중 실패 2(원래의 Windows 둘 `files-api` · C-49). e2e는 브라우저 없이 건너뛰므로 이 수에 e2e 통과는 들어 있지 않다.
- 뽑기 창(나-12) · MCP 원격(사-08) · 세컨드 브레인 넣기(바-06)는 코드와 시험만 봤다.
