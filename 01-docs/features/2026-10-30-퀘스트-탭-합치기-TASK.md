- 커밋 전 `python 04-tests/run_all_tests.py`(노드 시험 포함, `PUPPETEER_PATH` 없이 — 기준선은 Windows `files-api` · C-49 둘) · 링크 검사 `bash .claude/hooks/check-links.sh`. e2e는 따로 `PUPPETEER_PATH=<puppeteer-core 폴더> timeout 280 node --test 04-tests/e2e/<파일>.test.js`.
