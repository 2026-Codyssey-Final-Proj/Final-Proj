# 기능 줄이기 제안 — 무엇을 빼고, 무엇을 다듬고, 무엇은 건드리지 않나 (2026-10-31)

> **한 줄로:** 있는 기능 81개 중 **지우는 것은 0개**다 — 마감 전엔 코드를 지우지 않고 **사용자 눈앞에서 숨긴다**. 숨길 것 **6개**(처음 설정의 '같이 쓸 앱' 칸 · 뽑기 · 문서 지도 '상자' 보기 · 설정의 토큰 · GitHub 칸 둘 · 공부 묶음 단추), 다듬을 것 **7개**(캔버스 탭 순서 · 문서 틀 11 → 3 · 먹이 주기는 시연 흐름에서 빼기 · 더 보기 칩 정리 · 설정 묶음 6 → 4 · 관문 카드 단추 · 퀘스트 탭 받기 전 카드 글), **손대지 않을 것 40개**(1순위 16 + 장면 다섯의 2순위 24), 나머지 28개는 **보이지 않으니 그대로**. 대회 뒤 지울 코드 **2,900줄쯤**은 따로 적었다(5절).
> 하면 사용자가 처음 만나는 입구가 **처음 설정 6칸 → 5칸, 설정 묶음 6 → 4, 퀘스트 탭 보기 3 → 2, 작업실 머리 단추 −1, 더 보기 칩 −2**가 된다. 코드는 한 줄 ~ 수십 줄씩, 전부 되돌릴 수 있다.

## 0. 왜 "숨기기"인가 — 지금 일정에서 지울 수 없는 까닭

| 날 | 무엇 | 뜻 |
|---|---|---|
| **11/1(내일)** | 기능 동결 · 앱 11.0.0이 녹화 · 사용 테스트 · 제출의 같은 판(결정 모음 A-17) | 동결 뒤 바꾸는 것은 **작은 고침**만 — 단추 하나 숨기기는 되고, 기능을 뜯어내는 것은 안 된다 |
| **11/4 ~ 7** | 사용 테스트 5명 이상(비전공자 포함), 첫 가치까지 2분 | 사람이 **처음 켜서 2분 안에 길을 찾아야** 한다 — 입구가 많을수록 헤맨다 |
| **11/12 · 13** | 평가(발표 10분 + 질의응답 10분) | 보여 줄 수 있는 것은 **장면 다섯**(켜면 작업실 → 퀘스트 탭 → 관문 → 맡기기 → 기록)뿐 |

그래서 기준은 하나다 — **"장면 다섯과 사용 테스트 2분 안에 사람이 만나는가?"** 만나지 않는 것은 코드가 있어도 문제가 아니다(보이지 않는 기능은 사용자에게 없는 것과 같다). 만나는데 장면에 없고 설명이 필요한 것이 **빼야 할 것**이다.

- **지우기(코드 삭제)는 대회 뒤**로 미룬다. 지우면 시험이 깨지고(시험 파일 152개), 동결 판과 다른 코드가 되고, 되돌리기 어렵다. 숨기기는 단추 한 줄이고 시험 한두 개만 고친다.
- **1순위 바탕 16개와 장면 다섯의 2순위는 손대지 않는다.** 줄이려다 바탕을 건드리면 11/4 전에 다시 안정시킬 시간이 없다.
- 보안(가리기 · 빼 둘 곳 · 허락 훅)은 기능 수가 많아 보여도 **줄이지 않는다**(기록 기준 6-3).

## 4. 손대지 않을 것 — 40개

**1순위 바탕 16개**(우선순위 2절) — 줄이려다 건드리면 11/4 전에 못 돌아온다.
**장면 다섯의 2순위 24개** — 이것이 곧 발표다. 여기서 뺄 것은 없다. 오히려 **사람이 아직 앱에서 안 눌러 본 둘**(퀘스트 탭 · 처음 설정의 API 키 길)을 11/3까지 눌러 보는 것이 줄이기보다 먼저다.

왜 "기능이 많다"는 말이 나왔는가를 여기서 한 번 짚는다 — 81개 중 사용자가 2분 안에 만나는 것은 **1절 표의 입구들**이고, 나머지는 바탕(서버 · 창구 · 가리기)이거나 흐름 속에서 저절로 일어나는 것(훅 · 저장 · 되살리기)이다. **많아 보이는 것은 기능 수가 아니라 입구 수**다. 1절 표에서 장면 밖 입구는 11개(같이 쓸 앱 · 캔버스 · 뽑기 · 상자 · 칩 셋 · GitHub · 토큰 · 공부 묶음 둘)이고, 2절이 그중 **7개를 숨기고**(같이 쓸 앱 · 뽑기 · 상자 · GitHub · 토큰 · 공부 묶음 둘) 3절이 캔버스는 순서만, 칩 둘은 뒤로 보낸다.

## 확인 못 한 것

- **멘토링 피드백의 원문**을 보지 못했다. "기능이 너무 많다"가 **입구가 많다**는 뜻인지 **발표에 다 못 담는다**는 뜻인지에 따라 답이 다르다 — 전자면 2 · 3절, 후자면 3절 3번(흐름에서 빼기)이 핵심이다. 원문을 알려 주면 다시 맞춘다.
- 앱을 켜서 눌러 본 것이 아니라 코드와 두 문서로 판단했다. 숨길 자리의 줄 번호는 2026-10-31 `grep`으로 확인했다.
- 사용 테스트 참가자가 폴더를 연결할지(상자 보기 · 파일 칸이 의미 있어지는 조건)는 B-01 ~ B-04 설계에 달려 있다 — 보지 못했다.
