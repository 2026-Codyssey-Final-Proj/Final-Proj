Floe

AI가 코드를 써 주는 시대에,
끝까지 만들고, 이해하고, 배움이 쌓이게
길을 안내한다.

결과를 대신 만들지 않는다. 사람이 스스로 결정하게 한다.

말할 것 AI가 코드를 써 주는 시대, 그래서 오히려 끝까지 이해하며 만드는 게 어려워졌습니다. 저희는 그 사이를 안내하는 Floe를 만들었습니다.

코드는 나오는데, 지금 어디쯤인지 모르면 멈춘다기획 의도 — 문제 정의

멈추는 순간

AI가 만든 결과가 맞는지, 지금 어느 단계이고 다음에 뭘 해야 하는지 판단하지 못해 개발이 중간에 선다.

끝내도 남는 문제

끝까지 만들어도 내 코드를 설명하지 못하고, 배운 것이 다음 프로젝트로 이어지지 않는다.

인터뷰에서 들은 말 한두 줄 — 응답자 A처럼 이름 없이. 인터뷰(#11)는 보류 중이라, 없으면 "기획안의 가설"이라고 말하고 사용 테스트에서 들은 말로 채운다.
말할 것 바이브 코딩은 쉬워졌는데 "지금 어디까지 왔고 다음에 뭘 하지?"에서 멈춥니다. 끝까지 만들어도 내 코드를 설명하지 못합니다. (인터뷰 전이면 "가설"이라고 밝힌다.)

코딩을 배운 적 없어도, GitHub와 Claude Code만 있으면누가 쓰나

누구언제 쓰나
AI로 코딩을 배우는 학습자과제 · 프로젝트를 AI와 만들다 막힐 때 첫 검증 대상
코딩은 모르지만 AI로 서비스를 만드는 기획자 · 디자이너지금 단계와 내가 만든 것을 이해하고 싶을 때
개인 프로젝트로 바이브 코딩을 하는 직장인 · 창작자여러 프로젝트 사이에서 개발을 이어 갈 때

그래서 쉬운 말로 만들었다

화면의 큰 글에는 전문 용어를 쓰지 않고, 나오면 그 자리에서 풀어 준다.

사용 테스트에 비전공자가 몇 명 있었나.
말할 것 대상은 모두 "AI로 프로그램을 만드는 사람"입니다. 프로그래밍을 배운 적 없는 사람도 쓰도록 쉬운 말로 설계했습니다.

일을 한 칸씩 쪼개고, 단계가 끝나면 사람이 "이해했나요"를 누른다해결 한 장 — 퀘스트 한 바퀴와 관문

사용자의 Claude Code

코드를 쓰는 건 사용자의 도구. Floe는 일을 넘기고, 허용 · 거절을 섬에서 받는다

사용자의 GitHub 저장소

단계 문서와 README가 "책"의 원본. Floe는 받아 와 보여 주기만 한다
아키텍처 · 데이터 흐름 그림(입력 → 판정 → 설계도 → 이해 확인 → 기록). Jira KAN-31 · KAN-32에서 갱신한 그림을 넣는다. 그림이 갱신되기 전에는 이 장을 확정하지 않는다.
말할 것 로컬 앱 + 오버레이 + 사용자의 Claude. 키와 기록은 사용자 컴퓨터에만 있습니다.

판정은 코드 규칙이 하고, Claude는 초안과 설명만 한다AI 적용 — API를 그대로 쓴 것이 아닌 이유

사람
정한다 — 초안 확정, "이해했나요", 맡긴 일의 허용 · 거절
코드 규칙
판정한다 — 완료 기준 항목을 대조. 같은 입력이면 같은 답이라 시험할 수 있다
Claude
돕는다 — 초안 · 설명 · 리뷰 · 질문. 한 번에 한 조각만 맡는다

AI는 긴 단계를 기억하고 스스로 "다 됐다"고 판정할 때 약하다. 그래서 기억은 앱이, 판정은 코드와 사람이, AI는 한 조각만. 정확도 · 토큰 숫자는 출처를 확인한 뒤에만 넣는다(두승현 확인 전).

말할 것 판정을 프롬프트에 맡기면 같은 입력에 다른 답이 나와 시험할 수 없습니다. 그래서 판정은 코드 규칙, Claude는 초안 · 설명 · 리뷰. 확정과 이해 여부는 사람이 누릅니다.

아이디어 한 줄에서 관문을 넘기까지시연 영상 — 2분 30초

지금 넣은 건 40초 소개 영상이다. 3분 시연 스토리의 장면 1~8에서 2:30에 맞게 고른 구동 영상으로 바꾼다(이재엽 · 임유정). 화면의 "가상 숫자예요" 표시는 가리지 않는다.
말할 것 장면마다 한 문장만. 영상과 말이 겹치지 않게 — 리허설에서 소리 · 자막 필요 여부를 정한다.

써 보기 전과 후검증 — 숫자가 나오면 이 제목을 결론 문장으로 바꾼다

사용 전 — 다음 할 일을 찾는 데 걸린 시간, 설명할 수 있었나
사용 후 — 같은 항목. 5명 이상, 비전공자 포함(일정 11/4~7)
성공 수치 — 2단계에서 정한 목표 값과 실측 값. 못 잰 건 "못 쟀다"고 쓴다
말할 것 잰 값만 말한다. 못 잰 것은 못 쟀다고 말한다 — 지어낸 숫자보다 신뢰를 얻는다. 담당: 두승현(검증 결과) · 고한결(사용 테스트 진행).
