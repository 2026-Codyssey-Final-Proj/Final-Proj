"이어짐"과 "품"은 Claude의 어림이에요. 섞어도 돼요. 예를 들어 D의 첫 화면 아래에 B의 지도를 두거나, A의 밤하늘에 C의 플로로 하루를 넣을 수 있어요.

네 초안이 같이 지킨 것

  • 내용은 README, 기획안, 요구사항, 마스코트 README에서만 가져왔어요. 완주율 같은 숫자와 사용 후기는 아직 정하지 않았으므로 넣지 않았어요.
  • 플로로는 코드로 그린 그림(floro.svg)을 썼어요. 원본 그림(mascot-v1)은 이용 조건 확인 전이라 쓰지 않았어요.
  • 서버 주소, 저장소 주소, 팀원 이름은 넣지 않았어요.
  • 버튼은 초안이라 실제로 내려받지 않아요. 눌러 볼 수 있는 곳은 B의 문과 결정, C와 C 변형 셋의 용어 풀이와 쓰다듬기, D의 허용·거절이에요.
