플로로와 보내는 하루

Floe는 바이브 코딩을 대신 해 주지 않아요. 지금 무엇을 하면 되는지 알려 주고, 이해하고 넘어가게 하고, 배운 것을 남겨요.

  1. 말 걸기

    섬에 말을 걸면 플로로가 답해요. 파일을 끌어다 놓으면 읽고, 비밀번호나 개인적인 내용으로 보이는 곳은 빼요.

  2. 퀘스트 받기

    지금 단계에서 할 일을 퀘스트 하나로 줘요. 한 줄씩 물어보며 같이 채워요.

  3. 이해했나요?

    장을 넘어가기 전에 물어요. 아니라고 하면 헷갈린 곳부터 같이 봐요.

  4. 책 꽂기

    여덟 장을 다 지나면 무엇을 왜 정했는지 담긴 책 한 권이 서재에 꽂혀요.

  5. 쿨쿨

    1분 30초 가만히 두면 헤엄치다 졸고 잠들어요. 누르면 깨요.

여덟 장을 하나씩 건너요

단계는 장, 할 일은 퀘스트, 넘어가기 전 확인은 관문이에요. 섬을 누르면 그 장에서 하는 일과 받는 조각이 보여요.

Floe를 써도 사람이 없으면

초안을 모두 '맞아요'로 넘기면 관문 여덟 개를 지나도 아무도 읽지 않은 문서가 남아요. 4장은 '서버가 있는 웹'을 골랐는데, 코드를 짠 AI는 받은 글을 다시 읽고 명령줄로 만들었어요. 그리고 사람에게 물었어요.

## 정할 것
- CLI인가, 서버가 있는 웹인가 … 웹 화면을 더할지: ____
- API 요청 제한 시간(초) … 정할 값: ____
- 맛집 검색어 … 정할 검색어: ____
… 빈칸 8개, 답한 사람 0

"빈칸을 채워 줄 사람이 있어야 제가 쓸모 있어요."

잰 방법 — 세 길 모두 같은 미션 글로, Claude Opus 5.5(Floe 초안 · 대화는 Floe 기본값 Sonnet)를 한 번씩 돌렸어요. 시험 24개는 미션을 토대로 만든 기준을 가짜 AI · 지도 서버로 확인해요(진짜 키는 쓰지 않았어요). test-1은 사람이 Floe로 직접 지나간 기록이고, 그 토큰은 잰 값이 아니라 예상이에요. 자세한 표: Final-Proj-Result 저장소.

내려받고 폴더 하나만 이어요

지금은 알파 버전이에요. 새 버전을 깔기 전에는 켜져 있는 Floe를 먼저 꺼 주세요.

Mac

.dmg

Apple Silicon용이에요. Floe를 '응용 프로그램'으로 끌어 놓고 열어요. 경고가 뜨면 시스템 설정의 개인정보 보호 및 보안에서 '그래도 열기'를 눌러요.

Windows

.exe

내려받아 실행해요. SmartScreen 경고가 뜨면 '추가 정보'를 누른 뒤 '실행'을 눌러요.

우분투

.AppImage · .deb

AppImage는 파일 속성에서 실행을 허용한 뒤 두 번 눌러요. .deb는 설치해서 열어요.

  1. 앱을 처음 켜면 플로로가 물어요. Claude Code로 이을지, 내 API 키를 넣을지 골라요.

  2. 메뉴에서 "Floe → 프로젝트 폴더 연결"을 골라요. Windows와 우분투는 창을 우클릭해요.

  3. 섬에 말을 걸면 플로로가 "퀘스트를 시작하시겠습니까?"라고 물어요. 시작을 누르면 0장부터예요.

둘 다 없으면 연습 모드로 움직여요. API 키는 화면이나 기록에 남기지 않아요.

AI가 일하는 시대에도, 성장하는 건 사람이어야 해요.

Floe와 길잡이 물범 플로로. 코디세이 Final-Project 팀이 만들어요.
