옆자리 플로로

지금의 '시작하기' 카드를 플로로와 나누는 대화로 바꿔 본 목업이에요. 왼쪽에서 이야기하고, 아래 버튼으로 내가 할 일을 골라요. 버튼마다 누르면 무슨 일이 생기는지가 먼저 보이고, 플로로는 오른쪽에서 표정으로 따라와요. 두 화면 모두 직접 해 볼 수 있어요.

플로로 말투
1~6버튼 고르기Enter보내기플로로를 누르면 쓰다듬어요

지금 화면에서 달라지는 것

  1. 카드 하나 대신 이어지는 대화. 지난 결정과 Claude가 한 일이 위로 쌓여서, 올려 보면 어디서 무엇을 정했는지 보여요.
  2. 버튼은 내가 할 행동. 누가 하는지(Claude, 나, 플로로)와 드는 토큰이 버튼 아래에 먼저 보여요. 추천하는 하나만 밝게 칠했어요.
  3. 직접 하면 책갈피가 생겨요. Claude에게 맡긴 할 일과 내가 직접 쓴 할 일이 다르게 쌓여서, 배운 것이 서재로 이어져요.
  4. Claude가 한 일은 대화 속 작업 카드로. 어느 파일에 무엇을 더했는지 한 줄로 보여요.
  5. 잠긴 '다음 단계로'. 할 일이 남으면 점선으로 잠기고, 누르면 플로로가 무엇이 남았는지 알려 줘요.

같이 정할 것

  1. 플로로 말투를 친구처럼(반말) 할지, 다정한 존댓말로 할지. 위의 토글로 견줘 볼 수 있어요.
  2. 버튼 여섯 개가 많은지. 휴대폰에서는 옆으로 밀어서 봐요.
  3. 직접 쓴 할 일에만 책갈피를 주는 규칙이 맞는지.
  4. 대화 기록을 어디까지 남길지. 지금 화면처럼 이 브라우저에만 둘지.
  5. 작업 카드에 Claude의 실제 출력을 얼마나 보일지. 지금은 파일 이름과 한 줄만이에요.

목업이라 플로로의 답과 Claude가 한 일은 미리 정해 둔 글이에요. 서버와 AI를 부르지 않고, 아무것도 저장하지 않아요. 플로로 그림은 지금 제품의 seal.js를 그대로 썼어요.
