얼음판 전투

Floe의 작업 공간과 대화 창을 고전 RPG 전투 화면처럼 바꿔 본 목업이에요. 지금 단계에서 풀 문제가 적으로 나오고, Claude에게 일을 시키면 적의 칸이 줄어요. 할 일을 다 하면 적의 이름이 노래지고, 그때 넘어갈 수 있어요. 아래 두 화면은 직접 해 볼 수 있어요.

    같이 정할 것

    1. 버튼 말을 게임 말(공격, 행동)로 둘지, 일 말(만들기, 살피기)로 둘지. 처음 쓰는 사람에게 무엇이 쉬운지 위의 토글로 견줘 볼 수 있어요.
    2. 토큰을 HP로 보이면 줄어드는 게 불안할 수 있어요. 그대로 둘지, 숨길지, 다른 이름으로 할지.
    3. Claude의 턴에 하트를 움직이는 건 지금은 놀이일 뿐이에요. 시험이 실패하면 '맞았다'로 보여 줄지.
    4. 이 화면이 오버레이의 '이번 단계' 탭을 대신할지, 설정에서 고르는 게임 모드로 둘지.
    5. 휴대폰에서는 작업 공간을 두 줄로 줄였어요. 그걸로 충분한지.

    글꼴은 둥근모꼴과 Pretendard를 CDN에서 불러 그렸어요. 제품에 넣기 전에 이용 조건을 확인해야 해요. 고전 RPG 전투 화면의 짜임새만 빌렸고, 특정 게임의 캐릭터, 이름, 그림, 소리는 쓰지 않았어요.
