지금 오버레이를 키우고, 큰 글 칸 자리에 '지금 하는 일'만 가볍게 보이는 상자를 뒀어요. 아래 네 칸에서 할 일을 고르면 상자 안에 고를 수 있는 길이 펼쳐져요. 단계는 레벨이고, 할 일을 하나 끝낼 때마다 경험치 바가 차올라서 다 차면 레벨이 올라요.

지금 오버레이에서 달라지는 것

  1. 위 아이콘 줄과 플로로는 그대로. 네 아이콘과 설정, 열어 두기, 접기는 지금 모양이고, 플로로는 지금 카드처럼 얼음 숨구멍에서 물에 잠긴 채 고개를 내밀어요. 20초 동안 가만히 있으면 지금처럼 한 번 헤엄쳐요.
  2. 플로로 크기는 오버레이 크기를 따라가요. 플로로 칸의 너비와 높이 중 작은 쪽에 맞춰 90~300px 사이에서 정해요. 위의 크기 버튼이나 모서리 끌기로 해 볼 수 있어요.
  3. 큰 글 칸 대신 가벼운 상자. 지금 할 일 하나와 Claude Code에서 온 마지막 알림 한두 줄만 보여요. 글은 '직접 쓰기'를 고를 때만 한 줄로 열려요.
  4. 네 칸이 할 일을 고르는 자리. 맡기기, 살피기, 꺼내기, 쉬어 가기. 고르면 상자 안에 길이 펼쳐지고, 길마다 무슨 일이 생기는지(경험치, 토큰, 책갈피)가 먼저 보여요. '예시 글 넣기'와 '어디쯤인지 보기'도 이 길 안으로 들어갔어요.
  5. 단계는 레벨, HP는 경험치. 할 일 하나에 경험치 10. 다 차면 레벨이 오르고 다음 단계의 할 일로 바가 다시 비어요.
  6. 밖에서 일해도 차올라요. Claude Code에서 일하면 알림이 오고, 상자에 한 줄로 보이면서 경험치가 올라요. 위의 '알림 보내기' 버튼으로 해 볼 수 있어요.

같이 정할 것

  1. 레벨이 저절로 오르면 지금의 '넘어가기 전 확인'(확인 질문 하나)이 빠져요. 레벨 업 직전에 확인 질문을 하나 넣을지.
  2. 직접 써도 Claude에게 맡겨도 경험치는 10으로 같고, 직접 하면 책갈피만 더 생겨요. 직접 한 쪽에 경험치를 더 줄지.
  3. 버튼 말을 일 말(맡기기)로 둘지, 게임 말(공격)로 둘지. 위의 토글로 견줘 볼 수 있어요.
  4. 큰 글 칸이 없어도 처음에 무엇을 만드는지 말하기 충분한지.
  5. 휴대폰 화면은 이번에 그리지 않았어요. 네 칸을 2×2로 둘지.

목업이라 Claude가 한 일과 플로로의 말은 미리 정해 둔 글이에요. 서버와 AI를 부르지 않고, 아무것도 저장하지 않아요. 아이콘과 플로로는 지금 제품의 것을 그대로 썼어요.
