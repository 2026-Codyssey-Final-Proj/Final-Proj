# 0~8단계 스토리보드 — 디자인 첫 판

Floe로 무언가를 만들 때 시작(0)부터 8단계까지 화면에서 무슨 일이 일어나는지 보여 주는 한 페이지다. 예시는 이재엽이 Floe로 만든 공개 저장소 [gamercross/test-1](https://github.com/gamercross/test-1)(나만의 프롬프트 관리 프로그램)이다.
**제품 코드는 그대로다.** 팀이 화면 방향을 같이 보려고 만든 그림이다. <!-- claude-drafted: 2026-10-26 두승현 검토 --> **2026-10-26 이재엽 · 두승현이 이 방향으로 앱을 고치기로 정했다** — 11/1 기능 동결 전에, 작업실이 지금의 퀘스트 창을 대신한다(브랜치 `v2/ui-overhaul_du`). 요구서 2-2 C-41 등급 칸에 같은 결정을 적는다.

- **보기:** [index.html](index.html)을 브라우저로 연다(서버 · AI 없음). 같은 페이지가 claude.ai 아티팩트로도 있다 — https://claude.ai/artifact/SjXczGdWBh3cCDL3tahLYp (이재엽이 Share로 열어 줘야 팀원이 볼 수 있다).
- **기준:** [넘김 문서](../../00-overview/기록/opus-handoff-2026-10-26-storyboard.md)의 화면 기준 10 · 단계 0~8 뼈대, 그리고 디자인 캔버스(https://claude.ai/artifact/6FABoNXETGrPD9hiT8ungr) 맨 아래 줄의 DockPrototype · DockPositions. 장면 그림은 이재엽이 준 그 캔버스의 스크린샷(2026-10-26)을 따른다 — **3단계 장면이 그 스크린샷과 같은 순간**이다(스크린샷의 "2단계 · 꼭 필요한 기능"은 앱 번호로 3단계).

## 글은 어디서 왔나

- 장면의 문장 · 칸 · 커밋 · 시각은 test-1 `8e41922`의 `docs/` 문서와 커밋 기록에서 그대로 옮겼다. test-1에 없는 말(섬의 지금 카드, 플로로의 다음 말)에는 **예시**, test-1과 달리 이렇게 이어져야 할 모습(관문에서 멈추기, 실행 결과 · 시험 결과 자리, 행동 칸에서 Claude Code가 문서를 쓰기)에는 **이어져야** 표시를 붙였다.
- 그림 속 파일 이름은 test-1의 실제 이름이다(`docs/03-requirements/requirements.md` 등) — 스크린샷(club-events)의 이름을 따르지 않았다. 조개 수도 스크린샷('조개 3')과 달리 넘은 관문 수로 그렸다.
- 0단계 플로로의 첫 말은 [첫 5분 스토리보드](../onboarding-storyboard.md) S1에서, 3단계 섬의 말(맡기기 카드 · "다시 왔네요!")은 디자인 캔버스 스크린샷에서 왔다.
- '지금 앱에 있나'는 `main` `e6f4724`의 코드와 [요구서](../../00-overview/requirements.md) C-23 · C-37 · C-39 · C-40 기준이다. 5~8단계의 '확인한 대로'는 C-40(확인한 단계는 AI가 다시 살펴보지 않는다)에서 왔다.
- 버전 V.n은 디자인 캔버스처럼 관문마다 하나(1단계 → V.1)로 그렸다 — 규칙은 아직 정하지 않았다(C-23 ①). LV와 조개 수는 넘은 관문 수로 그렸다(C-28).
- 플로로 그림은 [floro.svg](../../../02-frontend/assets/mascot/floro.svg)에서 앱 아이콘 바탕 · 물웅덩이 그림자 · 별만 뺀 사본이 페이지 안에 들어 있다. 원본은 그대로다.

## 확인한 것 · 하지 않은 것

- **첫 판(카드 모양):** 데스크톱 폭(1280, 어두운 모드)으로 한 번 찍어 보고 고쳤다. 새 맥락 리뷰를 받아 지적을 고쳤다 — 휴대폰 폭에서 표 때문에 페이지가 가로로 밀리던 것, '예시' · '이어져야' 표시가 빠진 곳, 44px보다 작은 누르는 곳, 0단계 섬 머리가 "시작 시작"으로 겹치던 것, 눌러 보기에서 펼친 뒤 포커스가 사라지던 것 · 움직이는 동안 읽기 칸이 계속 바뀌던 것, '확인한 대로' 범위(5~8단계).
- **지금 판(스크린샷 기준):** 데스크톱 폭(1440, 밝은 모드)으로 한 번 찍어 0단계 · 3단계 장면을 봤다. 두 번째 새 맥락 리뷰가 test-1 원문과 대조하고 화면을 재서(500 · 1440 폭, 눌러 보기 36가지 조합) 지적한 것을 고쳤다 — 그림 속 파일 이름을 test-1 실제 이름으로, 3단계 파일 카드의 줄 수(원문은 한 줄 → "… 75줄 더"), '● 지금' 글씨 대비(4.13 → 4.5 이상), 너비가 44px보다 좁던 누르는 곳, 좁은 화면에서 듣지 않던 규칙 둘(파일 목록 숨김 · 보드 줄), 4단계 장면의 순간, 인용 두 곳.
- **남긴 것:** 눌러 보기 그림 안의 섬 머리 자리 단추 · 띠의 '펼치기' · 손잡이는 44px보다 작다 — 같은 일을 하는 44px 조작(섬 자리 단추 · 섬 접기 · 너비 슬라이더)이 바로 위에 있다.
