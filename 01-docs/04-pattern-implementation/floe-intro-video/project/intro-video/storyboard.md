## 1. 이 영상이 하는 일

- **이야기**: 막막함 → 플로로를 만남 → 플로로가 기능 4개를 차례로 보여 줌 → 같은 사람이 평가자에게 자기 코드를 막힘없이 설명 → 그 뒤에서 플로로가 흐뭇하게 바라봄 → Floe.
- **전하고 싶은 것**: 팀의 한 문장 "AI가 일하는 시대에도 성장하는 건 사람이어야 한다"(팀 저장소 `01-docs/00-overview/시연-한-줄기.md`). 결말은 플로로가 대신 해 주는 장면이 아니라, **사람이 스스로 설명할 수 있게 된 장면**이다.
- ①과 ④는 같은 하늘색 배경에 같은 사람(같은 옷)이 나와서 "전과 후"가 한눈에 비교된다.

## 2. 목표 · 하지 않을 것 · 실패로 볼 것

**목표**
- 처음 보는 사람도 40초 안에 이야기(막막함 → 도움 → 성장)를 따라간다.
- 영상 속 플로로가 실제 앱의 플로로와 똑같다.
- ③-2의 기능 이름 4개가 발표장 화면에서 읽힌다.
- 영상이 끝나면 "Floe"라는 이름과 문구가 남는다.

**하지 않을 것**
- 내레이션, 장면 설명 자막 (①·②·④·⑤는 그림과 소리만)
- 실제 앱 화면 캡처 (기능 칸은 단순한 도형으로 다시 그린다 — 그림체가 튀지 않게)
- 레퍼런스 그림 · 영상을 직접 넣는 것

**실패로 볼 것** (영상이 돌아가도 이러면 실패)
- 레퍼런스(빈칸 광고 · people style · scene01)를 베낀 것처럼 보인다.
- 플로로 생김새가 앱과 달라진다 — 플로로 그림은 두승현의 작업물이라 모양 · 색을 바꾸지 않는다.
- 기능 칸 글씨가 작아 안 읽히거나, 효과음이 음악보다 시끄럽다.

## 6. 만드는 법

```
intro-video/
├── storyboard.md     이 문서
├── sketches/         구도 스케치 (레퍼런스 그림은 뺀 캡처)
├── video/            영상 코드 — 장면 그림 · 시간표 · 효과음 합성 · 렌더 스크립트
├── build/            찍은 장면 · 중간 파일 (GitHub 제외)
├── final/            완성 mp4
└── refs/             레퍼런스 (GitHub 제외)
```

- 영상 코드는 **시간(초)을 넣으면 그 순간의 화면을 그리는** 방식으로 만든다. 그래서 브라우저에서 미리 보며 고칠 수 있고, 크롬으로 1초에 30장씩 정확히 찍을 수 있다.
- 플로로는 팀 저장소의 `02-frontend/navigator/seal.js` · `seal.css`, 글꼴은 `02-frontend/assets/fonts/`를 **읽기만** 한다(팀 파일은 고치지 않는다).
- 찍은 장면 1,200장을 ffmpeg로 mp4로 묶고, 효과음과 배경음악을 섞는다.
- 먼저 효과음만 넣은 판(`final/floe-intro-40s-sfx-only.mp4`)을 만들고, Suno 음악이 생기면 섞어서 완성판(`final/floe-intro-40s.mp4`)을 만든다. 중간 판도 지우지 않고 남긴다.

## 8. 제작하면서 정할 것 · Claude가 정한 것

**제작하면서 Claude가 맞춰 갈 것**: 움직임의 정확한 속도 곡선, 플로로가 뛰는 높이, 효과음 음색과 크기, 색의 미세 조정, 사람 그림의 세부(머리 모양 · 신발 등).

**Claude가 정한 것 — 확인해 주세요**
1. 전체 40초와 장면별 시간 배분
2. ② 노트북 화면이 물웅덩이처럼 일렁이는 연출, 그리고 플로로가 화면 속으로 다시 들어가며 ③-1로 "안내"하는 연결
3. ③-2 → ④ 연결: (처음엔 화면 밖으로 빠져나오기였으나 2차 다듬기에서) 플로로가 들어간 웅덩이에서 둥근 물결이 퍼지며 열림
4. ④ 배치(노트북은 사람 뒤 책상 위, 두 사람 모두 서 있음)와 평가자의 옷 색
5. ⑥ 로고 변신 때 "퐁당" 효과음 하나 추가
6. 글꼴은 앱 글꼴(Bagel Fat One · Gowun Dodum)
7. 첫 결과물은 효과음만 넣은 판, 배경음악은 Suno로 만든 뒤 섞기 (같은 날 새 세션에서 Suno 도구가 보여 바로 섞었다)

**제작하면서 Claude가 바꾼 것**
- ① 자세가 바뀔 때 두 자세를 겹쳐 흐리게 하지 않고 2.3초에 한 번에 바꾸고 움찔하는 반동을 넣었다(겹치면 몸이 비쳐 보였음).
- ② 플로로를 화면 밖으로 나오는 느낌이 나도록 키웠다.
- ④ 카메라가 다 빠져나온 뒤에도 1배가 아니라 1.16배로 두었다(두 사람이 작아 보였음).
- ⑥ 흰 막을 0.7로 진하게 하고 마크를 키웠다(흐린 배경이 문구와 겹쳐 보였음).
- 배경음악 크기를 "−14 dB 깎기" 대신 "−23 LUFS로 맞추기"로 바꿨다. −14 dB면 −28 LUFS로 너무 작아졌다.

**2차 다듬기 (2026-11-06, 사용자 피드백: "퀄리티가 안 좋고 첫 장면에서 팔이 겹친다" → 아쉬운 점으로 '움직임이 딱딱함 · 사람 그림이 단순함 · 장면 연결이 어색함'을 고름)**
- ① 턱 괴기 자세에서 두 팔이 몸통 왼쪽 같은 자리에서 나와 교차하던 것을, 팔꿈치를 책상에 댄 팔 하나로 바꿨다(시험: 한 자세 안에서 팔끼리 교차하면 실패).
- 영상으로 바꿀 때 색을 BT.709로 바꾸고 태그를 붙였다. 전에는 태그가 없어 재생기에서 색이 살짝 탁해졌다(실측 원본 226,244,253 → 재생 222,241,251, 고친 뒤 226,243,253). 압축 품질도 crf 18 → 14로 올렸다.
- 사람 그림을 위 그림체 규칙대로 다시 그렸다.
- 움직임: 자세 사이 중간 동작, 숨쉬기 · 눈 깜빡임 · 몸무게 옮기기 · 고개 끄덕임, ④ 손짓 세 번, 평가자의 귀 기울이기 · 체크리스트 두드리기, 플로로의 깜빡임 · 들어가기 전 예비 동작.
- 장면 연결: ②→③의 크게 비틀리며 확대되던 전환과 ③→④의 화면 밖으로 빠져나오기를, 플로로가 물에 들어간 자리에서 둥근 물결이 퍼지는 전환으로 바꿨다. 시작은 흰 화면에서 밝아진다. ⑤→⑥에서 플로로가 갑자기 몸 전체로 나타나던 것도 고쳤다.

## 9. 다시 만들기 · 고치기

`intro-video/` 폴더에서 실행한다. 필요한 것: Node 24 · 크롬 · ffmpeg (npm 설치 없음).

| 하고 싶은 것 | 명령 |
|---|---|
| 미리 보기(재생 · 시간 막대) | `node video/serve.mjs` → 나온 주소를 브라우저로 |
| 시험 (75개) | `node --test "video/test/*.test.mjs"` |
| 특정 순간만 찍어 보기 | `node video/render/render.mjs --stills 8.2,27.2` → `build/stills/` |
| 영상 다시 찍기 (약 3분) | `node video/render/render.mjs` → `build/video-noaudio.mp4` |
| 효과음 트랙 | `node video/audio/track.mjs` → `build/sfx-track.wav` |
| 소리 섞어 완성 | `node video/render/mux.mjs --video build/video-noaudio.mp4 --sfx build/sfx-track.wav --bgm build/bgm/suno-a-feed6383.mp3 --out final/floe-intro-40s.mp4` |

- 장면 시간은 `video/src/timeline.mjs`, 효과음 시점은 `video/src/cues.mjs`, 색은 `video/src/art/palette.mjs`, 장면별 움직임은 `video/src/scenes/s1.mjs`부터 `s6.mjs`까지에 있다.
- 플로로 그림은 팀 저장소의 `seal.js`를 그대로 읽으므로, 팀에서 플로로를 고치면 다시 찍을 때 영상에도 반영된다.
- **다시 만들 때는 먼저 지금 `final/`의 판을 `final/history/`로 옮긴 뒤 섞는다**(같은 이름으로 덮어쓰면 이전 판이 사라진다). 1차 판 mp4는 2차 판을 만들 때 덮어써서 폴더에 없다 — 필요하면 OneDrive 버전 기록에서 되살린다.
