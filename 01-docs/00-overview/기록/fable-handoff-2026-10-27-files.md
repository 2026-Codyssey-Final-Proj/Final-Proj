## 3. 꼭 지킬 것

- **Floe가 사용자 파일을 읽고 쓰는 새 길이다 — 보안 먼저.** [API.md](../../../03-backend/navigator/API.md)에 길을 먼저 적고 시험을 먼저 쓴다.
  - 연결한 프로젝트 폴더 안만. 경로를 요청에서 만들지 않는다(목록에서 받은 번호로 — `server.js` STATIC과 같은 생각). 심볼릭 링크로 밖에 나가지 않는다.
  - 숨김 파일 · 비밀값 파일(`check-secrets.sh` 금지 경로)은 목록에도 보이지 않고 열지도 쓰지도 않는다. 크기 · 확장자 한계.
  - 다른 컴퓨터에서 오는 요청은 받지 않는다(`allowed`). 쓰기는 이 컴퓨터의 앱에서만.
- **쓰기 규칙이 바뀐다** — 지금은 사용자 파일에 쓰는 것은 Claude Code가 허락받고(FR-17 · C-37). 사람이 Floe에서 직접 저장하는 길이 더해진다(이재엽 버튼 "읽기 + 고치기"). 저장을 섬에서 한 번 더 확인할지, 저장이 커밋까지 하는지는 이재엽에게 버튼으로.
- **문서 지도의 엔진:** 바깥 주소(GitHub Pages)에서 불러오면 앱이 밖으로 요청을 보낸다 — 앱에 한 벌 넣을지(제안) 이재엽에게 버튼으로. 바깥 주소로 가면 [security-records.md](../../../.claude/rules/security-records.md) 3절(밖으로 나가는 것)에 한 줄.
- md.sumzip.com에 로그인하거나 거기에 프리셋을 세팅하지 않는다(계정은 다루지 않는다).
- 화면은 C-42와 같은 기준(파스텔 + 섬 네이비 · 대비 4.5:1 · 44px · 쉬운 말 · 마우스 따라오기 없음). Claude는 `main`에 올리지 않는다. 변경 기록 조각은 `changes/workspace-files.md`, 쓴 곳에 `claude-drafted`.
