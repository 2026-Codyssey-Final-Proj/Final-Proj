# 넘김 — Mac에서 받은 앱이 열리지 않는다 (F-41 · F-42 · F-44)

> **기록 문서.** 2026-10-20 앱 8.1.0 기준이다. 고칠 목록은 [fix-map.md](../../07-maintenance/fix-map.md) **F-41 ~ F-44**(F-43 안내 고침은 이 문서와 같은 PR에서 끝남). 기준은 **Mac dmg**다 — Windows · Linux는 Mac이 끝난 뒤 같은 방식으로 본다.

## 0. 먼저

1. 이름 확인(CLAUDE.md "처음 세션이면") → 이 문서 → fix-map F-41 ~ F-44.
2. **이 문서를 담은 PR이 병합된 뒤** 최신 `main`에서 브랜치를 딴다.
3. 차례: **F-41(치명) → F-42 → F-44(낮음).** F-41 · F-42는 한 릴리스로 [제안].
4. 시험을 먼저 써서 지금 묶음에서 실패하는 것을 본 뒤 고친다(code.md 1번).
5. 앱 버전은 이재엽이 "버전업"이라고 할 때만 — 고침이라 **8.1.1** [제안].

## 1. 정하신 것

- 기준: "일단 맥 dmg 파일로 기준을 잡을게"
- 8.1.0 릴리스 설명에 지금 여는 법을 넣기 — **Go**(끝남)
- Apple 개발자 서명 · 공증 — **Hold**. 이재엽 "지금 내가 배포를 하는것도 아닌데 dmg를 만드는데도 패킹을 할때도 돈이 들어?" → 묶기 · 간이 서명은 무료, 돈이 드는 것은 다른 사람 Mac에서 경고 없이 열리게 하는 Apple 서명뿐이라 팀원만 쓰는 동안은 하지 않는다.

## 2. 확인한 것 (8.1.0 dmg)

| 무엇 | 결과 |
|---|---|
| 묶는 설정 | `package.json` `build.mac.identity: null` — 서명을 건너뛴다 |
| 앱 서명 | 실행 파일만 adhoc · linker-signed. `codesign --verify --deep --strict` 실패, `syspolicy_check distribution` **Fatal** |
| 앱 전체 간이 서명을 한 사본 | 검증 통과. 남는 것은 'adhoc — 배포용 아님' 경고(Apple 서명이 아니라서)뿐 |
| 앱 자체 | 정상 — 인터넷 표시 없이 따로 켜면 서버 · 화면이 뜬다 |
| 옛 앱 | 이 Mac에 8.0.0이 켜져 있었다. `main.js`에 한 번에 하나만 켜는 장치가 없다 |

## 3. 할 일

- **F-41** — 앱 전체에 **간이 서명**(ad-hoc)을 하고 묶는다. 방법(electron-builder 설정인지, 묶은 뒤 `codesign`인지)은 **문서를 열어 확인한 뒤** 고른다. CI Mac 단계에서 묶은 앱을 `codesign --verify --deep --strict`로 검사해 **실패하면 릴리스를 올리지 않는다**. 고친 뒤에는 처음 열 때 '시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기'로 열리는지 사람이 확인한다 — 그다음 안내서 셋(team-guide 2-c · release-notes · electron/README)을 그 방법으로 고친다.
- **F-42** — 한 번에 하나만 켜지게 한다. 두 번째로 켜면 켜진 쪽을 앞으로. 켜진 쪽이 옛 버전이면 무엇을 할지(알리기 · 바꿔 켜기)는 페이블 세션이 정해 이재엽에게 버튼으로 묻는다.
- **F-44** — dmg 창에 'Floe를 응용 프로그램으로 끌어 놓으세요'가 보이게(낮음).

## 4. 꼭 지킬 것

- **인증서 · 암호 · Apple 계정은 다루지 않는다**(Hold). 간이 서명은 비밀값이 필요 없다.
- 앱의 들어 있는 것(서버 · 화면 · `hook.js` 풀어 둔 것)을 바꾸지 않는다 — 서명만.
- 사람이 앱에서 확인하지 않은 것을 '확인함'으로 쓰지 않는다(경고 창 문구는 아직 화면에서 보지 않았다).
