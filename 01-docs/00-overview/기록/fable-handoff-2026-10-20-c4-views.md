## 2. 할 일

### ① 책 보기 설정 — FR-8 세부(C-9 · C-3)

- 책 화면에 '보기 설정' 하나: 구조(간결 · 탭 [제안]) · 칸 켜기/끄기(지나온 단계 · 정한 것 · 배운 것 · 만든 것 · 책갈피 · 할 일 — 내용은 지우지 않는다) · 보기(짧게 · 전체 화면 · **세션별 · 책별**).
- 설정은 이 컴퓨터에 저장해 다음에도 쓴다(서버 없이, FR-10). 칸을 새로 만들거나 자유롭게 옮기지는 않는다(규격화한 길).
- '세션'은 코딩 도구에서 연 작업 한 번으로 읽었다(C-3 ①) [해석]. 기본 보기 · 기본 구조는 페이블 세션이 정해 이재엽에게 버튼으로 묻는다.

### ② FR-17 — 대화로 일 넘기기 · 섬에서 진짜 허용 · 거절(C-4)

- 대화창에 적은 일 → 요구 문장으로 정리 → 사람이 고쳐 확정(FR-3과 같은 흐름).
- 허락하면 사용자의 Claude Code 세션에 넘겨 이어서 하게 하고, 그 진행을 섬에서도 보인다(AI 진행 C-12와 같은 자리 [제안]).
- Claude Code가 파일을 고치거나 명령을 쓰기 전에 허락을 구하면, 섬에 승인 카드(무엇을 · 바뀔 내용) → 사람이 누른 대로 따른다. 되돌리기 어려운 일(삭제 · 강제 푸시 · 키 노출)은 한 번 더 묻는다.
- 서버 없이(FR-10)는 미리 만든 승인 카드 · 바뀔 내용 한 장면.

## 3. 꼭 지킬 것

- **대신 허용하지 않는다.** 답이 늦거나 Floe 서버가 꺼져 있거나 오류가 나면 Claude Code 자기 확인으로 넘긴다 — 저절로 허용하는 길이 없어야 한다.
- **결정은 그 요청과 짝이 맞을 때만** 쓴다 — 늦게 온 결정 · 다른 요청의 결정은 버린다(요구서 C-4 ③, 장부 W-25 · W-26).
- **바뀔 내용은 승인 카드에서만, 가려서(`sensitive.js`) 보이고 저장 · 전송하지 않는다.** AI 진행(C-12)의 '이름 · 첫 줄 · 줄 수만'은 그대로다 — 두 길을 섞지 않는다.
- 지금 훅은 Claude Code를 **기다리게 하지 않는다**(`hook.js`). 기다리는 훅은 새로 두고, 지금 훅의 원칙은 바꾸지 않는다.
- 결정을 받는 서버 길은 이 컴퓨터(127.0.0.1)와 확인 값(지금의 `X-Nav-Token`)으로 막는다. 요청 판정 순서(인증 → 권한 → 소유권 → 사업 조건)와 거부 응답을 표로 적는다([보안 기준](../../../.claude/rules/security-records.md) 6-3).
- Claude Code를 실행할 때는 셸을 거치지 않고, 연결한 프로젝트 폴더 안에서만 실행한다.
- Claude Code 훅의 모양(어떤 훅이 허락을 받을 수 있는지, 시간 상한)은 **문서를 열어 확인한 뒤** 쓴다 — 추측하지 않는다.
- coucou의 승인 · diff 화면은 동작만 참고한다. 이름 · 그림 · 소리 · 예시 데이터는 옮기지 않는다(legal.md D-1).
