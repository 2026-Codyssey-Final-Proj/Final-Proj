| 해결 | 내용 |
|---|---|
| 결정 카드 | 아래 3절의 표에 **체크만** 하면 결정이 된다 — 글을 쓰지 않아도 됨 |
| 기한 규칙(제안) | 10/22까지 답이 없는 칸은 **제안안을 잠정 채택**한다. ADR 상태는 Proposed 그대로 두고, 구현은 진행할 수 있다. 나중에 바꾸면 새 ADR로 대체 |
| 결정 대기 중에도 가능한 일 | 두승현: fixture 3단계 장면, 안전장치 S1~S6 / 임유정: 화면 구조 보강 / 고한결: 인터뷰 진행 — 이 일들은 결정을 기다리지 않는다 |

## R3. 리뷰·권한 장치가 약함

**현재 확인한 것 (2026-10-16):** 비공개 저장소, 이재엽 admin, 나머지 3명 maintain. `main` 보호는 무료 비공개 플랜에서 켤 수 없다. 병합된 PR 중 리뷰 0건이 많다. LICENSE 파일 없음.

| 해결 | 내용 | 상태 |
|---|---|---|
| PR 템플릿 | 리뷰어 지정·이슈 링크·테스트·비밀값·claude-drafted 확인 칸 | **이 PR에 포함** |
| 리뷰 한 명 규칙(제안) | 병합 전 **본인 외 한 명**이 코멘트 한 줄. 아주 작은 문서 수정은 예외 | 이재엽 동의 필요 |
| 브랜치 정리 | 병합된 원격 브랜치 11개 삭제(2026-10-16). 팀원 브랜치 5개(고한결 4, 임유정 1)는 본인이 정리 | **완료** |
| 병합 뒤 브랜치 자동 삭제 | 저장소 설정 한 줄(admin) | 이재엽이 켜기 |
| LICENSE | 방향은 MIT로 모임(#51: 이재엽·두승현·임유정). **조건 둘** — ① 대회 규정(소유·사용 범위) 확인 ② 고한결 동의. 저작권자 표기도 정해야 함 | **대기** — 조건이 충족되면 PR |

- [ ] 리뷰 한 명 규칙을 `TEAM.md` 협업 규칙에 한 줄로 쓴다 — 이재엽
- [ ] 저장소 설정에서 병합 뒤 브랜치 자동 삭제 켜기 — 이재엽
