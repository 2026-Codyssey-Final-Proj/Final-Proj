## 5. 비교 사진 만드는 법 — 앱을 띄우지 않고 같은 화면을

작업실 창(`navigator/win.html#quest`)은 섬이 보낸 HTML을 그대로 보인다(`win.js onWinHtml`). #212부터 섬이 보내는 것은 **작업실 판(`qwinHTML`) + 섬 옆 칸(`.isl-col`)**이다(`app.js islCol`). 그래서 브라우저에서 같은 화면을 만들 수 있다.

1. 서버를 다른 포트로: `NAV_PORT=4399 node 03-backend/navigator/server.js`
2. 헤드리스 Chrome을 디버그 포트와 새 프로필로: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --remote-debugging-port=9334 --user-data-dir=<scratchpad>/profile about:blank` — `/json/version`이 답할 때까지 기다린다(몇 초 걸린다).
3. DevTools 프로토콜(Node의 `WebSocket`)로:
   - `http://127.0.0.1:4399/#ex=2&q=quest`를 열고 `[data-act="qtab"][data-tab="canvas"]`를 누른다. `.qwin`의 `outerHTML`과 `.isl`의 `outerHTML`을 꺼낸다.
   - 새 탭에 `Page.addScriptToEvaluateOnNewDocument`로 `window.floeApp = { onWinHtml: f => window.__h = f, onDock: f => window.__d = f, winEvent: () => {} }`를 넣는다. 그 뒤 `navigator/win.html#quest`를 창 크기(S/M/L · 화면 가득)로 연다.
   - `__h(qwin + '<div class="isl-col side-right narrow">' + isl + '</div>')`를 부른다.
   - `.cv` 너비 · `.cvb` 너비(÷ 1100 = 배율) · `scrollWidth > clientWidth`(넘침)를 재고 `Page.captureScreenshot`으로 찍는다.
4. 스토리보드 3단계 장면을 같은 폭으로 찍어 나란히 둔다.
5. 끝나면 띄운 서버와 Chrome만 끈다.

진짜 앱으로도 한 번 — `npm start`(Electron)를 CDP로 재는 법은 #207 ~ #212 본문의 "실제로 본 것"을 따른다(Windows에서 해 봤다). Mac(노치 · '위' 자리)은 아직 아무도 못 봤다.
