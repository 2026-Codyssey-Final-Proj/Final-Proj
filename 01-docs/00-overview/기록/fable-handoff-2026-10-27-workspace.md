브라우저로 같은 화면을 재현해 쟀다(5절 방법, 3단계 연습 장면 `#ex=2&q=quest`, 캔버스 탭).

| S 720 × 520 | 520px | **89px** | 662px · 두 줄 |
| M 920 × 640 (처음 값) | 720px · 두 줄 | **289px · 세로 한 줄** | |

- #211 본문도 같은 것을 적었다: "섬이 옆에 붙어 420을 차지하면 M · L 창의 보드는 254 · 456px이라 세로 한 줄" — R-1(화면 가득)이 이것을 푼다.

## 5. 비교 사진 만드는 법 — 앱을 띄우지 않고 같은 화면을

작업실 창(`navigator/win.html#quest`)은 섬이 보낸 HTML을 그대로 보이고, 섬이 붙으면 그쪽에 여백을 둔다(`win.js onWinHtml` · `onDock`). 그래서 브라우저에서 같은 화면을 만들 수 있다.

1. 서버를 다른 포트로: `NAV_PORT=4399 node 03-backend/navigator/server.js`
2. 헤드리스 Chrome을 디버그 포트와 새 프로필로: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --remote-debugging-port=9333 --user-data-dir=<scratchpad>/profile about:blank`
3. DevTools 프로토콜(Node의 `WebSocket`)로:
   - `http://127.0.0.1:4399/#ex=2&q=quest`를 열고 `[data-act="qtab"][data-tab="canvas"]`를 눌러, `.qwin`의 `outerHTML`을 꺼낸다(3단계 연습 장면).
   - 새 탭에 `Page.addScriptToEvaluateOnNewDocument`로 `window.floeApp = { onWinHtml: f => window.__h = f, onDock: f => window.__d = f, winEvent: () => {} }`를 넣는다. 그 뒤 `navigator/win.html#quest`를 화면 크기(예: 1440 × 875)로 열고, `__h(html)` · `__d({ side: "right", size: 431, inner: 420 })`를 부른다.
   - `.cv-board`의 안쪽 너비를 재고(`clientWidth − padding`), `Page.captureScreenshot`으로 찍는다.
4. 스토리보드 3단계 장면을 같은 폭으로 찍어 나란히 둔다.
5. 끝나면 서버와 Chrome을 끈다(띄운 PID만 — 다른 세션의 서버를 끄지 않는다).

진짜 앱으로도 한 번 — `npm start`(Electron)를 CDP로 재는 법은 #207 ~ #210 본문의 "실제로 본 것"을 따른다(Windows에서 해 봤다). Mac(노치 · '위' 자리)은 아직 아무도 못 봤다.
