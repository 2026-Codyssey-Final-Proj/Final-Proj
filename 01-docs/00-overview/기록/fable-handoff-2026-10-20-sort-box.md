# 넘김 — 먹이 주기에 종류와 서재의 분류함 (FR-15 · C-15, C-8에서 빠졌던 것)

> **기록 문서.** 2026-10-20 `main` c0e210c 기준이다. 요구는 [requirements.md](../requirements.md) 2절 **FR-15**와 2-2 **C-15**(더한 두 문장) · **C-8**(원래 문장), 한 말 그대로는 13-1.

## 0. 먼저

1. 이름 확인(CLAUDE.md "처음 세션이면") → 이 문서 → 요구서의 FR-15 · C-15 · C-8 행.
2. **이 문서를 담은 PR이 병합된 뒤** 최신 `main`에서 브랜치를 딴다.
3. 먹이 주기(8.1.0, [앞 넘김 문서](fable-handoff-2026-10-20-feed.md))와 서로 막기(C-19, [넘김 문서](fable-handoff-2026-10-20-motion.md))를 건드리는 일이라, 그쪽이 진행 중이면 먼저 끝낸 뒤 시작한다.
4. 시험을 먼저 써서 지금 코드에서 실패하는 것을 본 뒤 만든다(code.md 1번). 앱 버전은 이재엽이 "버전업"이라고 할 때만.

## 1. 정하신 것

- C-8 원문(2026-10-17): "내가 어떤 내용들을 넣으면 분석하고 확인 시켜주는 내용" / "서재 창고로 내가 어떤 내용들을 분석하고 분류 해야하는지 보여줌"
- 오늘 C-8을 C-15(먹이 주기)로 합쳤는데, C-15 문장에는 **종류 나누기**와 **분류함**이 들어가지 않았다(Claude가 합칠 때 놓침).
- 버튼: **"먹이 주기에 더하기"** — FR-15 · C-15에 다시 넣는다.

## 2. 할 일

- 먹이 정리에서 **빠지지 않은 구간마다 종류 하나** — 요구 · 결정 · 배운 것 · 할 일 · 참고. 사람이 맞는지 확인하거나 고친다. 빠진 구간(비밀번호 · 개인적인 일)은 분류하지 않는다.
- 아직 확인하지 않은 구간은 서재의 **분류함**에 모인다. 거기서 확인하면 그 종류로 책에 들어간다(내 책의 칸 — 정한 것 · 배운 것 · 할 일 등과 어떻게 이을지는 페이블 세션이 정해 버튼으로 묻는다).
- 서버 없이(FR-10)는 예시 먹이의 구간에 미리 만든 종류.

## 3. 꼭 지킬 것

- 종류를 AI로 붙인다면 **빠진 구간은 보내지 않는다**(FR-15 그대로). 외부 AI 호출은 provider.js 한 곳.
- AI가 붙인 종류는 틀릴 수 있다 — **사람이 확인하기 전에는 책에 넣지 않는다**(C-8 ②).
- 화면 글은 쉬운 말(FR-13). '분류함'이라는 이름이 어렵게 들리면 바꿀 후보를 이재엽에게 버튼으로 묻는다.

## 4. 끝나면

- `python3 04-tests/run_all_tests.py` — e2e가 건너뛰지 않았는지 본다.
- requirements.md FR-15 상태 '만드는 중' → '만듦', C-15 '확인할 것' ⑥ ⑦에 정한 값.
