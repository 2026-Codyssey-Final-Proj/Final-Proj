# C-38 결정 자료 — 플로로가 만든 정보를 다른 AI 도구로 넘기기 (2026-10-25)

| 항목 | 내용 |

| 결정 | **이재엽** — 2026-10-24 결정("앱 + 훅 그대로, MCP · 스킬을 더하지 않는다")과 닿는 일이라 |
| 요구 후보 | [requirements.md](../requirements.md) 2-2 **C-38** · 2-3 |

## 1. 문제 — 두승현의 말

> 현재 플로로는 초보자가 사용하는 웹페이지에서 가동하는 클로드, 웹페이지에서 가동하는 gpt 또는 VS코드와 같은 환경과 같이 작업하기에는 적합하지 않다. 따라서 이를 개선하는 것이 필요하다. MCP 등으로 플로로가 생성한 정보를 넘기는 방안을 검토 중이다.

**지금:** Floe는 **Claude Code(터미널 프로그램)와만** 이어진다 — 훅(Claude Code → Floe 알림 · 허락)과 `claude -p`(Floe → Claude Code). 웹 Claude(claude.ai) · 웹 ChatGPT · VS Code의 AI는 Floe가 아는 것(지금 단계 · 할 일 · 계획)을 모른다.

**10/24 결정과의 관계:** 그 결정은 "새 저장소에서 Floe와 **Claude Code**를 무엇으로 잇나"에 대한 답이었다([요구사항](../requirements.md) 13-1, C-32). 이번 물음은 **Claude Code 밖의 도구**라 범위가 다르다 — 그래도 같은 물음(MCP를 들이나)을 다시 여는 것이라 결정을 받는다.

## 2. 무엇을 주고받나

### 2-1. AI 도구가 Floe에서 읽어 가는 것

| 정보 | 지금 Floe의 어디 | AI가 하는 일 |
|---|---|---|
| 지금 단계와 다음 할 일 하나 | 판정(FR-1 · [API](../../../03-backend/navigator/API.md) 3-6) | 지금 할 일에 맞춰 답한다 |
| 이 단계의 완료 기준과 채운 칸 | 단계 할 일(`navigator.js`, FR-2) | "다 됐어요" 대신 빠진 칸을 짚는다 |
| 지금 퀘스트 | C-22 · API 3-17 | 사용자가 적은 줄을 이어 받는다 |
| 준비 계획 · 맡길 일 · 기준 | C-34 · API 3-20 | 계획을 다시 세우지 않고 그 기준대로 |
| 단계 문서 · README 책 | API 3-18 · 3-22 · 3-23 | 앞에서 정한 것을 알고 답한다 |
| 쉬운 말 규칙 · 용어 풀이 | `glossary.js` · C-33(초등 고학년) | 웹 AI도 같은 쉬운 말로 |

### 2-2. AI 도구가 Floe에 보내는 것

| 정보 | 지금 비슷한 것 | Floe가 하는 일 |
|---|---|---|
| 한 일 보고 | 훅 알림 · AI 진행(API 3-2 · 3-12) | 섬의 알림 · AI 진행 판 |
| "이 할 일 끝냈어요" | 판정(3-6) | **판정은 Floe의 코드가 한다** — AI가 통과를 정하지 않는다(ADR-0003) |
| 헷갈린 것 질문 | 물어보기(3-7) | 쉬운 말로 답한다 |
| 허락 요청(IDE에서 파일을 고칠 때) | 승인 카드(3-13 ~ 3-15) | 섬에서 허용 · 거절 |
| 단계 문서 초안 | 초안 · 다시 봐 주기(3-8 · 3-9) | 사람이 고쳐 확정한다 |

### 2-3. 보내지 않는 것 — 지금 규칙 그대로

키 · 토큰 · 비밀번호 · `.env`, 먹이 주기가 뺀 구간(개인적인 일 · 비밀번호처럼 보이는 것), 파일 원문 전체(지금도 이름 · 첫 줄 · 줄 수만 — `steps.js`), 다른 사람의 정보.

### 2-4. 먼저 해야 할 일 — 상태를 서버로

지금 단계 · 퀘스트 · 계획 같은 정보는 **서버가 아니라 화면 쪽(앱의 브라우저 저장소)**에 있다. 어떤 길로 넘기든 MCP 서버가 읽어 주려면 이 정보를 Floe 서버가 들고 있어야 한다 — 길 2 ~ 4의 공통 선행 작업이다(길 1 넘김 카드는 화면에서 바로 만들어 필요 없다).

## 3. 도구마다 MCP를 받는가 — 2026-10-25 확인

| 도구 | 받는 MCP | 조건 |
|---|---|---|
| **웹 Claude**(claude.ai) | 원격만 | Anthropic 클라우드가 **공개 인터넷에서 닿는 서버**에 접속한다. 내 컴퓨터 안의 서버는 claude.ai에서 쓸 수 없다 |
| **웹 ChatGPT** | 원격만(개발자 모드) | Plus · Pro · Business · Enterprise · Education, 설정에서 켜야 한다. OpenAI가 "강력하지만 위험하다"고 경고한다(프롬프트 주입 · 지우는 일) |
| **VS Code** | 내 컴퓨터 안(stdio)도 | Copilot 에이전트 모드, `.vscode/mcp.json` |
| **Claude Desktop**(앱) | 내 컴퓨터 안(stdio)도 | `claude_desktop_config.json` |
| ChatGPT 데스크톱 앱 | **확인 못 함** | — |

**왜 같은 노트북이어도 웹은 안 되나:** 웹 채팅 화면은 내 브라우저에 뜨지만, MCP로 Floe에 접속하는 쪽은 **AI 회사의 서버**다. 그 서버에서 `127.0.0.1`은 자기 자신이라 내 노트북의 Floe에 닿지 못한다.

## 4. 길 넷

| | 길 | 되는 곳 | 우리가 만들 것 | 사용자가 할 일 | 밖으로 · 보안 | 11/1 전에 |
|---|---|---|---|---|---|---|
| **1** | **넘김 카드** — Floe가 지금 단계 · 할 일 · 기준을 한 덩어리 글로 복사, 채팅에 붙여 넣고 답은 Floe의 먹이 주기(붙여 넣기 — 있음)로 돌려받기 | **모든 곳** | 섬에 "넘김 카드 복사" 단추 하나 · 쉬운 말 규칙을 담은 글 틀 | 복사 · 붙여 넣기 | 사용자가 붙여 넣는 AI 회사로만 — 복사할 때 비밀값 가리기(`sensitive.js`, 지금도 느낀 점 복사에 씀) | **된다** |
| **2** | **내 컴퓨터 안 MCP**(stdio) — Floe 옆 작은 MCP 서버, 읽기 도구 위주 | VS Code · Claude Desktop | MCP 서버 + 상태를 서버로(2-4) | 설정 파일에 한 줄 | 지금과 거의 같다 — 내 컴퓨터 밖으로 Floe가 열리지 않는다 | 빠듯하다 |
| **3** | **길 2 + 외부 브라우저 확장**(예: MCP SuperAssistant — 웹 ChatGPT · Gemini 등에 내 컴퓨터의 MCP를 잇는다) | 길 2 + 웹 ChatGPT | 길 2와 같다(확장은 남의 것) | 확장 설치 + 중계 프로그램 켜기(`npx`) | **외부 확장이 채팅 화면을 읽고 쓴다** — 들이기 전 점검([external-integration.md](../../../.claude/rules/external-integration.md)). 웹 Claude 지원은 확인 못 함 | 어렵다 |
| **4** | **원격 MCP** — Floe를 공개 서버로(또는 내 컴퓨터 + 터널) | 웹 Claude · 웹 ChatGPT | 공개 서버 · 인증(OAuth) · 사용자 구분 · 보관 | 연결 설정(유료 요금제) | **Floe가 인터넷에 열린다** — 인증 없으면 누구나, 일 넘기기 · 문서 쓰기가 열리면 밖에서 내 컴퓨터의 Claude Code를 움직이는 길이 생긴다. FR-10(서버 없이 시연) · 보안 기준 6-3(공개 전 인증)과 부딪친다 | 안 된다 |

**어느 길이든 지킬 것:** ① 판정은 Floe의 코드(ADR-0003) ② **쓰기 도구(일 넘기기 · 문서 쓰기 · 허용 · 거절)는 밖에 열지 않는다** — 열어도 읽기 도구만 ③ 정보가 AI 회사로 가는 것 자체는 지금 Claude Code와 같은 성격이라 [보안 기준](../../../.claude/rules/security-records.md) 3절에 받는 곳 한 줄을 더하면 된다 — 새로 생기는 위험은 **공개 서버 · 외부 확장** 쪽이다.
