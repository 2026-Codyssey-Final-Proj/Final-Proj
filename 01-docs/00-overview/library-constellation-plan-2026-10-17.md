## 0. 한 문장

**서재의 책마다 책갈피(표시해 둔 지식)가 별이 되고, 책갈피 사이의 연결이 별자리 선이 된다.** 이해가 깊어질수록 별이 밝아진다.
데이터는 Neo4j 그래프 모양으로 설계하고, **시연(11/8)은 그 그래프에서 뽑은 것과 같은 모양의 JSON으로 서버 없이** 그린다(FR-10).

## 5. 설계 초안 — 그래프와 화면

### 5-1. 그래프 모양 (Neo4j)

```cypher
// 노드
(:Book     {id, title, edition, printing, emblem})        // emblem = 윤곽 그림 이름
(:Bookmark {id, title, line, story, source, createdAt, level,  // story = 펼친 책의 지식 이야기 · level 0 처음 봄 … 3 응용함 (FR-8)
            x, y})                                        // 별의 자리 (D3 가) — 0~100 비율
(:Stage    {n, name})                                     // 워크 프로세스 단계
(:Concept  {name})                                        // 모르는 말 풀이(FR-13)와 이어짐

// 관계
(:Book)-[:HAS]->(:Bookmark)
(:Bookmark)-[:NEXT]->(:Bookmark)                          // 같은 책 안의 별자리 선 (꽂은 순서)
(:Bookmark)-[:RELATES {why}]->(:Bookmark)                 // 다른 책과의 연결 (베타의 은하 지도)
(:Bookmark)-[:CITED_IN {at}]->(:Stage)                    // "이 단계에 쓰기" — 인용 기록
(:Bookmark)-[:ABOUT]->(:Concept)

// 화면 한 장이 부르는 질의 — 결과를 fixture JSON과 같은 모양으로 돌려준다
MATCH (b:Book {id: $book})-[:HAS]->(m:Bookmark)
OPTIONAL MATCH (m)-[:NEXT]->(n:Bookmark)
OPTIONAL MATCH (m)-[c:CITED_IN]->(:Stage)
RETURN b, m, n.id AS next, count(c) AS cited
```

**fixture JSON 모양 (시연·테스트의 계약)** — Neo4j가 꺼져 있어도 같은 모양으로 그린다.

```json
{ "book": { "id": "b1", "title": "로그인 만들기", "emblem": "key" },
  "stars": [ { "id": "m1", "title": "세션과 토큰의 차이", "line": "…", "level": 2, "cited": 3, "x": 30, "y": 22 } ],
  "links": [ { "from": "m1", "to": "m2", "kind": "NEXT" } ] }
```

### 5-2. 별자리 화면 — 원신 "운명의 자리"에서 가져올 원리

| 원리 | 원신에서 | 우리 화면에서 |
|---|---|---|
| 윤곽 문장 | 캐릭터 실루엣이 옅은 선으로 깔림 | **책의 윤곽 그림**(열쇠·나침반·책 등)이 옅은 얼음 파랑 선으로 깔림 — 그림은 우리가 그린다 |
| 꼭짓점 별 | 별 6개가 윤곽 위 정해진 자리에 | 책갈피가 윤곽 위 정해진 자리에(D3 가) |
| 별을 잇는 선 | 별끼리 직선 | `NEXT` 관계를 직선으로 |
| 하나씩 켜짐 | 운명의 자리를 열면 별이 밝아짐 | **이해 수준(level)** 에 따라 밝기 4단계, 인용되면 빛 번짐 |
| 밤하늘 | 청록 성운 | 얼음 파랑 밤하늘(팀 테마 C-3) |

**별을 누르면 펼친 책** (이재엽 요청 2026-10-17 — "별자리 지도를 눌렀을 때는 책에서 보이도록", 메이플스토리의 펼친 책 화면을 예로 줌. 그림은 쓰지 않고 배치 원리만 가져왔다)

| 자리 | 보이는 것 |
|---|---|
| 왼쪽 쪽 | 그 책의 **책갈피 목차** — 고른 책갈피가 강조되고, 옆에 이해 수준 |
| 오른쪽 쪽 위 | 책갈피 이름 띠 |
| 그림 칸 | 이 책의 별자리를 작게 그리고 **펼친 책갈피의 별만 밝힘** |
| 이야기 | **지식 이야기** — 언제·왜·무엇을 배웠는지 내 말로 쓴 요약(본문 복사가 아님). 그래프에서는 `Bookmark.story` |
| 아래 | 이해 수준·쓰인 횟수·한 줄, "별자리로 돌아가기" / "이 단계에 쓰기" |

닫기는 ✕·Esc·바깥 누르기. 좁은 화면에서는 목차 위, 이야기 아래로 쌓인다. 주소 끝에 `#m1`을 붙이면 그 책갈피를 펼친 채로 열린다(시연·녹화용).

**접근성:** 밝기만으로 구분하지 않는다 — 별 옆에 레벨 글자(처음 봄 … 응용함)를 함께 보이고, 글자는 배경 대비 4.5:1 이상.
**최악 데이터:** 책갈피 0개(빈 상태 문구), 40개(자리가 모자랄 때 자동 배치로), 긴 제목(말줄임) — 임유정의 확인 목록에 넣는다.

시안(가상 데이터, 서버 없음): [`../04-pattern-implementation/bookmark-constellation-mock.html`](../04-pattern-implementation/bookmark-constellation-mock.html) — 브라우저로 바로 연다.

## 8. 이 문서가 하지 않는 것
