# 평가 발표 예상 질문 — 질문 세트 (KAN-47)

평가는 **발표 10분 + 질의응답 10분**이다([schedule.md](schedule.md) 1절). 질문은 Claude가 만들고 **답은 사람이 한다**([review-mode.md](../../.claude/rules/review-mode.md) "리뷰 렌즈"). 그래서 이 파일에는 답이 없다.

| 항목 | 내용 |
|---|---|
| 이슈 | Jira KAN-47 "예상 질문 카드 — qa-prep 스킬" (기한 11/11) |
| 질문 수 | 27개 (유형 5가지) |
| 답하는 사람 | 질의응답은 질문 유형별로 나눈다 — 기술은 이재엽 · 임유정, 사용자 · UX는 고한결, 검증은 두승현 ([schedule.md](schedule.md) 3-2) |
| 상태 | 질문 27개. **답변 카드 19장은 [qa-cards.md](qa-cards.md)에 문서 근거 초안으로 있다**(2026-10-24, 고한결 위임 — 발표자가 확인하기 전). 재료 칸이 "공백"인 질문은 지금 답할 근거가 없다는 뜻이다. 인터뷰(#11)는 **보류**(고한결 2026-10-24) |

## 쓰는 법

1. 담당 질문의 "답의 재료"를 열어 읽는다.
2. **내 말로** 답을 적거나 소리 내어 말한다 — 이 파일에 쓰지 말고 `qa-prep` 스킬에서 "이 질문으로 카드를 만들어줘"라고 한다. 스킬은 사용자가 말한 것만 쓰고, 없는 자리는 "미확인"으로 둔다.
3. 재료가 **공백**인 질문은 먼저 공백을 채울 일(인터뷰, 사용 테스트 등)을 한다. 채울 수 없으면 "아직 못 했다 — 이유와 앞으로의 계획"을 답으로 준비하는 것도 방법이다 (지어낸 답보다 낫다).

재료 상태: **있음** = 근거 문서 · 코드가 있다 / **일부** = 있지만 숫자 · 결과가 빠졌다 / **공백** = 근거가 아직 없다.
