# 사용자 시험 셋째 — 계획 (2026-11-07 초안)

**이 문서는:** Claude가 Floe 앱을 사람처럼 켜서 처음 설정부터 8단계 '마치기'까지 지나며 확인할 항목이다.
**임유정이 읽고 고치거나 더한 뒤** 시험을 맡긴다. 시험이 끝나면 각 줄의 '결과' 칸을 채우고, 문제는 [고칠 목록](../07-maintenance/fix-map.md)에 새 F-번호 묶음으로 옮긴다.

- 지난 시험: 첫째(2026-11-05) [user-test-fixes.md](../07-maintenance/fixes/user-test-fixes.md) · 둘째(2026-11-06) [user-test-fixes-2.md](../07-maintenance/fixes/user-test-fixes-2.md). 둘 다 **채팅(플로로 대화창)과 단계 흐름** 위주였다.
- **이번에 새로 보는 것:** 작업실 창의 **퀘스트 탭 — 지도 · 흐름 보기**가 채팅과 같이 맞물려 움직이는지. 그리고 지난 두 시험에서 '앱 확인 전'으로 남은 고침들.

## 2. 판정 · 적는 법

| 등급 | 뜻 |
|---|---|
| **막힘** | 더 나아갈 수 없거나, 틀린 결과가 남는다(기록 · 문서 · 단계가 틀림) |
| **불편** | 나아갈 수는 있지만 헷갈리거나, 화면끼리 말이 다르거나, 같은 일을 두 번 해야 한다 |
| **사소** | 글자 · 조사 · 자리 · 움직임 같은 작은 것 |
| **통과** | 기대대로 |

- 줄마다 '결과' 칸에 등급 + 한 줄. 막힘 · 불편은 스크린샷을 남긴다(레포에 올리지 않는다 — 키 · 메일이 보일 수 있다).
- **화면끼리 맞물림(4절)**은 한 동작마다 채팅 · 지도 · 흐름 세 곳을 같이 본다 — 한 곳만 바뀌면 '불편' 이상.
- 플로로의 말이 화면과 다르면(없는 단추를 말함, 틀린 숫자) 사소한 것이라도 적는다.
