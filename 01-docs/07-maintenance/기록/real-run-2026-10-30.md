# 진짜 AI로 한 바퀴 — 1 ~ 3단계 (2026-10-30)

> **한 줄로:** 진짜 AI(이 Mac의 Claude Code — 구독)로 1 → 2 → 3단계 관문까지 돌았다. **멈춘 곳 없이 끝까지 갔다.** 가장 큰 문제는 **글이 너무 길다**는 것이다. 섬의 퀘스트 카드는 칸을 확인할수록 앞 칸을 다시 늘어놓아 **317px → 763px**로 커진다. 관문 카드는 **1,155px**(섬 높이 약 800px를 넘음), 한 장 카드는 **최대 759px**다.
> 연습용 저장소(임시 폴더, 팀 저장소 밖)에서, 브라우저 판(1440 × 900, headless Chrome)으로 했다. 앱(Electron) 창이 아니다.

## 1. 어떻게 했나

- **기준:** `main` `3d388c6`. #286(C-47 한 장)이 병합된 뒤다.
- **연습 폴더:** `git init` + README 한 줄만 둔 새 폴더다. 서버는 앱처럼 `useProject`로 그 폴더를 가리켰다.
- **저장 파일:** 사용량 · 대화 · 빼 둘 곳 파일은 모두 임시 폴더에 두었다(`NAV_USAGE_FILE`). 실제 앱 기록과 섞이지 않는다.
- **AI 부르기:** API 키 없이 했다. 그래서 AI는 `claude -p`(이 Mac에 로그인된 Claude Code)로 불렸다.
- **훅 연결:** 연습 폴더에만 연결했다(`connect.js --apply`). 문서 올리기를 해 보려면 필요했다.
- **보낸 아이디어:** "동아리 행사 신청을 단톡방에서 받아 누가 신청했는지 놓친다. 이름을 적고 신청하면 한 목록에 모이고, 마감이 지나면 막는 작은 웹 앱. 운영진 세 명이 목록을 본다."
- **고른 것:** 칸은 플로로 초안에 거의 '맞아요'만 눌렀다. 크기는 '보통'이다. 관문마다 '배운 것' 한 줄을 적었고, 1단계 기준 카드에는 다룰 정보 · 성공 두 칸을 적었다.

## 4. 발견 — 중요한 순서

1. **퀘스트 카드가 칸마다 길어진다.**
   - 지금 칸 아래에 앞에서 확인한 칸의 글을 다 늘어놓는다(칸마다 4 ~ 7줄).
   - 그래서 2단계 넷째 칸에서 763px가 된다.
   - 확인한 칸은 이름만(또는 접힌 한 줄로) 두면 절반 아래로 줄어든다.
2. **관문 카드가 섬보다 길다(1,155px).**
   - 기준 카드(입력 넷), 받은 글 원문 132자, 한 장, 배운 것 칸이 한 카드에 함께 있다.
   - 아래로 스크롤해야 '네, 이해했어요'가 보인다.
3. **한 장 카드가 방금 확인한 칸을 다시 보인다.**
   - 크기는 525 · 759 · 720px다.
   - '정한 것' 칸에 칸 글이 ' / '로 이어져 7줄이 된다.
   - 한 장은 요약이니 칸마다 한 줄로 자르는 편이 맞다.
4. **AI 초안 글이 길다.**
   - 2단계 첫 칸의 초안은 152자로, 다섯 빈칸을 한 줄에 넣었다.
   - 제목 뒤에 용어 칩이 붙어 3줄이 된다.
   - 묻는 말 상한(지금 없음)과 초안 한 칸 상한(예: 60자)이 있으면 좋겠다.
5. **화면에 전문 용어가 보인다.**
   - 제목 끝 용어 칩: 규모 등급 · 의도명세 캔버스 · Planguage · MoSCoW·Kano · 추적표 RTM · 보안 점검 — 보안 요구(EARS Unwanted) · 표준 카탈로그(아키텍처 5대 스타일)
   - 누르면 풀이가 나오는 칩이지만, 제목 줄을 늘리고 처음 보는 사람에게 어렵다.
6. **문서 올리기에 반응이 없었다(연결 전).**
   - 훅이 연결되지 않은 폴더에서 '올리기'를 누르면 서버가 409(허락 카드를 띄우는 연결이 없음)로 답한다.
   - 그런데 카드는 그대로이고, 까닭은 지난 말로만 쌓인다. 사람은 아무 일도 안 일어난 것으로 본다.
   - 실제 앱은 폴더 연결 때 훅을 넣는다. 그래도 연결이 빠진 폴더라면 같은 일이 난다.
7. **'허락 카드가 떠요'라고 했는데 뜨지 않았다.**
   - 훅을 연결한 뒤 올리기를 누르니 Claude Code가 허락 카드 없이 문서를 쓰고 커밋했다(`docs: Floe 단계 문서 · 기획서 · 결정 기록`).
   - 원격이 없어 푸시는 없었다.
   - 미리 허락된 일이라면 안내 글을 고치고, 아니면 왜 안 물었는지 봐야 한다.
8. **올리기 뒤 저절로 AI를 두 번 불렀다.**
   - 훅 알림(Claude Code가 한 일)을 보고 4단계 퀘스트를 다시 맞췄다.
   - 35초, 22,983토큰이 들었다. 이 실행 전체에서 Floe가 쓴 토큰의 44%다.
   - 사람이 누르지 않은 부르기다.
9. **섬의 플로로 그림이 채팅 맨 위를 가린다.** 지난 말의 앞부분이 그림 밑에 숨는다.
10. **관문 · 확인 질문 · 올리기 제안은 다시 켜면 사라진다.**
    - 저장하지 않는 화면이라, 관문 중간에 창을 닫으면 '확인하고 넘어가기'부터 다시 해야 한다.
    - 주소에 `#start`를 붙여 열면 기록이 모두 처음으로 돌아간다. 시험할 때 쓰는 것이지만 주의가 필요하다.
11. **AI 오타:** 3단계 초안에 "아아직 정한 시각 없음"이 나왔다.
12. **노트북은 아직 갈색 양피지다.** C-68(우리 색으로)에서 다룬다.

## 5. 잘 된 것

- 1 → 3단계 관문까지 오류나 멈춘 곳 없이 갔다. 초안은 모두 4 ~ 13초 안에 왔다.
- 플로로 초안이 처음 말한 글을 잘 옮겼다. 2단계 이후에도 '재료 — 1단계 Ⅰ 불편 …'처럼 어디서 왔는지 보인다.
- **넘김 카드(C-38):** 복사와 카드가 됐다. 글은 658자다.
- **빼 둘 곳(C-52):** 설정 '기록' 탭에 적고 저장했다(200). 폴더 이름과 '막지 못하는 것' 안내가 보였다.
- **한 장(C-47):** 관문 앞에 카드가 떴고, '맞아요'를 누른 뒤 문서 올리기에서 README의 Floe 절에 단계마다 '— 한 장' 절로 들어갔다.
