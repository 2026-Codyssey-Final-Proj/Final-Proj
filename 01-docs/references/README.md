# 레프런스 창고

<!-- claude-drafted: 2026-10-15 — 이재엽의 요청으로 Claude가 만든 틀이다. 규칙은 팀이 고친다. -->

팀이 화면(UI)·기능을 만들 때 참고할 **자료를 모아 두는 곳**이다. 시안, 링크 모음, 이미지, 외부 도구 메모를 여기에 둔다.
**결정은 여기서 하지 않는다** — 이 폴더의 것은 제안·참고이고, 결정은 담당 역할과 팀 합의로 하고 해당 문서(ADR·요구사항)에 적는다.

## 폴더

| 자리 | 무엇 | 올리는 사람 |
|---|---|---|
| [`alcovibe/`](alcovibe/README.md) | 이재엽의 개인 프로젝트 "Alcovibe"에서 가져온 화면 테마·스타일 가이드 후보·이미지 | 이재엽 |
| `<이름>/` | 각자 가져온 자료는 자기 이름(또는 출처 이름)의 폴더에 | 각자 |

새 묶음은 폴더를 하나 만들고 안에 `README.md`(무엇·어디서 왔나·확인 수준)를 둔다.

## 올릴 때 지킬 것

| 규칙 | 이유 |
|---|---|
| **출처를 적는다** — 어디서, 누가, 언제 | 나중에 판단·갱신하기 위해 |
| **확인 수준을 적는다** — `검색 요약` / `직접 열어 봄` / `직접 만듦` | 요약만 본 것을 확정처럼 읽지 않게 |
| 남의 저작물(게임 화면·아트북·사이트 캡처)은 복사하지 않고 **링크만** | 저작권 |
| 이미지는 **생성 도구 약관과 워터마크를 확인**하고, 워터마크가 있으면 자른 파일을 올린다 | 사용 가능 범위 |
| **개인 정보 없음** — 이름·연락처·계정·인터뷰 응답자 식별 정보 | 보안 기준 4절·5절 |
| 파일 이름은 `<번호>-<설명>.webp`(또는 `.png`), 한 번에 10개 이하 | 찾기 쉽게 |
| 큰 파일은 **2MB 이하**로 줄인다 | 저장소 용량 |

## 이미지를 올리는 법

1. 해당 묶음 폴더의 `images/`에 파일을 둔다(예: [`alcovibe/images/`](alcovibe/images/README.md)).
2. 폴더 `README.md`의 이미지 표에 한 줄을 더한다: 파일, 용도, 만든 도구, 워터마크 처리 여부.
3. 브랜치로 PR을 올린다(`main` 직접 푸시는 사람만 — 루트 `CLAUDE.md` "브랜치·커밋").
