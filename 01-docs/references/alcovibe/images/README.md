# 이미지 자리

이재엽이 시안 이미지를 올리는 곳이다. 규칙은 [레프런스 창고](../../README.md)의 "이미지를 올리는 법"을 따른다.

## 올릴 때 확인할 것

- [ ] 생성 도구의 이용 약관(상업·공개 이용 범위)을 확인했다
- [ ] 워터마크(오른쪽 아래 별 모양 등)를 **자른 파일**이다
- [ ] 개인 정보·계정·화면 캡처에 든 이름이 없다
- [ ] 한 파일 2MB 이하, 이름은 `<번호>-<설명>.webp`

## 목록 (올리면 한 줄씩 더한다)

| 파일 | 용도 | 만든 도구 | 워터마크 처리 |
|---|---|---|---|
| (아직 없음) | | | |

시안이 담으려는 8가지는 [library-theme-prompts.md](../library-theme-prompts.md)에 있다: 표지(책+아치), 목록 화면, 빈 상태(빈 서가),
가로 배너(복도), 라이트 틀, 아이콘 12종, 스타일 보드, 시작·로딩 화면(계단).
