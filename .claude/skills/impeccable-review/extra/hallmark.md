**이 파일은 우선순위가 아니다.** `impeccable-review`가 필요할 때만 여는 참고이고, 혼자서 반응하는 스킬이 아니다.
우리 규칙(파스텔 · 쉬운 말 · [리뷰 모드](../../../rules/review-mode.md))과 다르면 **우리 규칙이 이긴다.**
지적할 때 근거는 `hallmark 2a`처럼 번호로 붙이고, 등급은 이렇게 옮긴다(리뷰 모드의 '막힘'은 우리 DoD · 규칙을 어겼을 때만):

| Hallmark 등급 | 우리 리뷰에서 |
|---|---|
| 바닥(Floor) — 원본에서는 넘기지 못함 | **보완** |
| 습관(Reflex) — 이유가 있으면 넘어가도 됨 | **제안(선택)** |

## 2. 다시 만들 때 — 잃은 것이 없나 (원본 `redesign` 확인을 손으로)

화면을 크게 고치거나 다시 짤 때, **고치기 전에** 아래를 세어 적고 고친 뒤 다시 센다. 하나라도 줄었으면 그 줄을 지적한다(보완).
줄인 것이 의도라면 PR 본문에 "뺀 것"으로 적게 한다.

| 셀 것 | 어디서 |
|---|---|
| 링크 | `<a href>` |
| 양식과 입력 칸 | `<form>` · `<input>` · `<select>` · `<textarea>` |
| 처리기 | `onclick` 등 속성, `addEventListener`가 붙는 대상 |
| 시험이 잡는 것 | `04-tests/e2e/`가 쓰는 선택자 · `data-*` |
| 스크립트 | `<script>` |
| 제목 | `h1` ~ `h6`의 수와 순서 |
| 그림 | `<img>` · `<figure>` · 설명 글 |
