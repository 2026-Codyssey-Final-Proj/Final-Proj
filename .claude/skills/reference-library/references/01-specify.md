# 1단계 — 비즈니스 모델 템플릿 30개

원문(캔버스 섹션 전체): `~/proj/coding_marathon_result/코딩마라톤 가이드/1. 명세 작성/비즈니스 모델 템플릿/README.md`

## 쓰는 법

- 1단계에서 "누구에게 무엇을 어떻게 팔거나 제공하나"가 비어 있을 때 쓴다. 개인 도구·학습 프로젝트처럼
  돈이 오가지 않으면 **린 캔버스의 문제·솔루션·핵심 지표 칸만** 빌려 써도 된다.
- 고른 템플릿의 캔버스 섹션은 PRD의 칸으로 옮겨 적을 재료다 — 섹션마다 한 줄 답을 사용자가 쓴다.
- 하나만 고르기 어려우면 **기본 틀(1~3) 하나 + 업종 틀 하나**로 겹쳐 본다. 예: 린 캔버스 + 구독 박스.
