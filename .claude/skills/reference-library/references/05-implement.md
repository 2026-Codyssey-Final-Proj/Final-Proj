# 5단계 — 구현 실행 (Implement): 화면과 운영 로그

원문: `~/proj/coding_marathon_result/코딩마라톤 가이드/5. 구현 실행/<폴더>/README.md` (폴더 5개). 화면을 만들 때는 먼저 루트 `CLAUDE.md` 라우팅의
"화면(UI)" 줄을 따르고([patterns.md](../../../../01-docs/catalog/patterns.md) UI 패턴 카드, 미적 방향은
`frontend-design`), 이 표는 **라이브러리·패턴 후보를 넓게 볼 때** 쓴다.

## 디자인 패턴 — 화면 패턴 (12)

| 패턴 | 난이도 | 쓰는 곳 | 확인할 것 |
|---|---|---|---|
| 대시보드 레이아웃 | 초급 | 관리자 화면, 현황판 | 좁은 폭(390px)에서 사이드바가 접히나 |
| 사이드바 내비게이션 패턴 | 중급 | 메뉴가 많은 앱 | 접힌 상태를 기억하나 |
| 데이터 테이블 패턴 | 중급 | 목록·검색·정렬 | 데이터가 많을 때 서버 쪽에서 페이지를 나누나 |
| 다단계 폼 위자드 | 중급 | 가입, 긴 입력 | 중간에 나갔다 돌아오면 입력이 남아 있나 |
| 모달 다이얼로그 패턴 | 초급 | 확인·짧은 입력 | Esc로 닫히고 포커스가 갇히나 |
| 토스트 알림 패턴 | 초급 | 저장됨·실패 알림 | 실패는 사라지지 않게 — 보안 기준 6-1 "숨기지 않는다" |
| 스켈레톤 로딩 패턴 | 초급 | 불러오는 중 | 실패했을 때 스켈레톤이 영원히 남지 않나 |
| 무한 스크롤 패턴 | 중급 | 피드 | 끝·오류 상태와 "맨 위로" |
| 검색 자동완성 패턴 | 중급 | 검색창 | 입력마다 요청하지 않게 지연(debounce) |
| 커맨드 팔레트 패턴 | 중급 | 키보드 중심 도구 | 단축키가 브라우저 단축키와 겹치지 않나 |
| 드래그 앤 드롭 패턴 | 고급 | 순서 바꾸기, 칸반 | 키보드로도 순서를 바꿀 수 있나 |
| 온보딩 플로우 패턴 | 중급 | 첫 사용 안내 | 건너뛰기와 다시 보기 |
