## 0. 한 문장

**서재는 "쌓인 것의 표지만 보여 주고, 자세한 것은 열 때 그 자리에서 가져오는" 화면이다.** 안내 패널은 서재를 **제안**만 하고 열고 쓰는 것은 사용자가 한다.

이름: 화면의 기능 이름은 **서재**로 쓰고, "도서관" 같은 은유는 빈 상태·보조 문구에만 쓴다(기능 이름·버튼은 기능 이름 그대로 — 쉬운 말 규칙 FR-13).

## 1. 서재 캔버스 (의도명세 캔버스 형식을 줄인 것)

| 블록 | 내용 |
|---|---|
| 개요 | 사용자가 만든 결정·요구·배운 것을 **책**으로 보이는 화면. 책 한 권은 폴더 하나, 표지에 판·쇄·권수 |
| 미션 | 쌓인 것을 다시 꺼내 쓰게 한다 — "AI가 일하는 시대에도 성장하는 건 사람"(FR-8) |
| 핵심 활동 | 책장 보기 → 책 표지·목차 보기 → 이 단계에 쓰기(인용) → 다른 곳에서 표지 가져오기 |
| 핵심 파트너 | 사용자의 작업 저장소(읽기), 이 컴퓨터의 Claude(요약·제안), 안내 패널(마스코트) |
| 핵심 장벽 | 가져오는 것에 **개인 정보·본문이 섞이는 것**(FR-9), 데이터원 미확인(시연은 가상), 인터뷰 전 가설 |
| 가치제안 | 내가 만든 것이 **어디에 어떻게 기록됐는지** 스스로 확인된다(책자 설계 0절) |
| 부정적 영향 | 안내만 따라 인용해 스스로 판단이 약해질 수 있음 [제안] / 남의 정보가 표지에 올라올 수 있음 |
| 이네이블러 | 책 표지 규약(판·쇄·권수·갱신), 공유 규칙(나만 보기 기본), 안전장치 S1~S6 |
| 핵심 데이터 | 이름·번호·상태·날짜·출처·한 줄 / **본문은 가져오지 않는다** |
| 범위 | 아래 4절 |

## 2. 보여 주는 법 — 화면

| 단계 | 사용자가 보는 것 | 설명 |
|---|---|---|
| ① 책장 | 책 5권 안팎이 꽂힌 한 줄 | 책마다 이름·권수·판쇄. 비어 있는 책은 "아직 쌓인 것이 없어요(인터뷰 뒤에 채워져요)" |
| ② 책 표지·목차 | 목차 표(이름·만든 날·출처·인용 횟수) | 표지에서 **본문은 안 보인다**. 열려면 "열기"를 눌러 원본이 있는 곳에서 가져온다 |
| ③ 확인 칸 | "자동으로 만든 날짜"와 "사용자가 훑은 날짜"를 따로 | 자동 통과와 사람이 본 것을 섞지 않는다 |
| ④ 역량 지도 | 레벨 4단계(처음 봄 → 이해함 → 직접 씀 → 응용함)와 한 일 | FR-8, 항목은 인터뷰 뒤 확정 |

**화면 위치:** 패널(작게) + 넓은 화면(서재처럼 넓어야 하는 것만 크게 펼침) — 임유정의 화면 구조 초안과 같다(`../../frontend/README.md`).

## 3. 주고받는 법 — 안내 패널 ↔ 서재

| 언제 | 패널이 하는 일 | 사용자가 하는 일 | 서재에 일어나는 일 |
|---|---|---|---|
| 서재를 열 때 | "지식이 2권 쌓였어요. 어떤 책부터 볼까요?" **선택지 카드 2개** | 하나를 누른다 | 책장이 열린다 |
| 책을 열었을 때 | 지금 단계와 이어지는 이유를 한 줄로 | "이 단계에 쓰기" | 그 책의 항목에 **인용 +1**이 기록된다 |
| 가져오기 | "표지만 가져와요. 자세한 건 열 때 가져와요" | 연결을 누른다 | 책장에 새 책이 생긴다(표지만) |
| 문제가 생겼을 때 | "잘 안 됐어요"로 정직하게 | — | 아무것도 지어내지 않는다 |

**규칙 다섯 가지**

1. 패널은 **제안만** 한다. 서재를 열고 쓰는 것은 사용자가 누른다(결정은 사람 — FR-3의 정신).
2. 인용은 **사용자가 "쓰기"를 눌렀을 때만** 올라간다. 열어 봤다는 이유로 올리지 않는다.
3. 선택지는 한 번에 **하나만 묻는 카드**다. 입력창은 "기타"를 눌러야 열린다(프로토타입·화면 구조 초안과 같음).
4. 서재의 값은 패널이 **계산하지 않고** 받은 값을 보여 주기만 한다(판정은 화면에서 안 한다).
5. 같은 행동을 두 번 눌러도 **같은 결과**다(멱등).

## 4. 가져오는 법 — 다른 데이터

핵심은 **"표지만 가져오고, 본문은 열 때 원본에서"** 이다. 사용자가 말한 방식("결과물 md만 남기고 자세한 내용은 그 작업 저장소에서 가져온다")과 책자 설계의 표지 규약을 그대로 쓴다.

| 경로 | 가져오는 것 | 가져오지 않는 것 | 시연(11/8) | 베타 |
|---|---|---|---|---|
| **이 컴퓨터의 폴더** | 책 표지의 머리말(책·자리·판·쇄·갱신·권수) | 문서 본문 | 가상 폴더 | 읽기 |
| **GitHub 비공개 저장소** | 같은 표지, 사용자 **자기 권한**으로 읽음 | 본문(열 때만) | 가상(연결하는 척) | **읽기, 권한 확인 필요** |
| **링크(레퍼런스)** | 주소와 한 줄 | 본문 복사 | 가상 | 읽기 |
| 팀 문서 | 이미 이 저장소에 있음 | — | 해당 없음 | — |

**가져올 때 걸러지는 것:** 키·비밀번호·전화번호 모양, 남의 이름(이름·직책·한 줄만), 본문 전체. 걸리면 **"그대로 진행 / 수정"** 을 고르게 하고 값은 다시 보이지 않는다(보안 기준 6-3).
**읽기 전용:** 가져오기는 원본을 고치지 않는다. 쓰기는 표지를 만드는 쪽이 한다.

## 8. 이 문서가 하지 않는 것

- 저장소를 연결하는 코드는 쓰지 않았다(제출 이후 구현).
- 실제 사용자 데이터를 가져오지 않았고, 목업은 가상 데이터다.
- 레퍼런스 링크는 검색 요약 수준이다. 쓰기 전에 열어서 읽는다.
