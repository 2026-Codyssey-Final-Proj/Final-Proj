# 도와준 사람들

Project Navigator를 만드는 데 도움을 준 분들을 **한 곳에** 모은다. 다른 문서에는 다시 적지 않는다.

## 적는 규칙

1. **이름은 본인 동의를 받은 뒤에만** 적는다. 동의가 없으면 이름 없이 "N명"으로 적는다.
2. 한 줄은 `이름(또는 N명) — 어떤 도움 — 언제`. 직책·소속은 본인이 원할 때만.
3. 연락처·메일·사적인 이야기는 적지 않는다.
4. 인터뷰에 응한 사람은 이름 대신 `응답자 A` — 이 문서에 올리지 않고 인터뷰 요약에서만 쓴다.
5. 동의를 받으면 "동의" 칸에 날짜를 적는다. 동의를 철회하면 줄을 지운다.

## 채우는 순서

1. 이재엽이 도움 준 분의 이름 후보를 정한다 (교수님, 대회에서 만난 분들).
2. 한 분씩 이름을 올려도 되는지 묻는다.
3. 동의한 분만 표에 옮기고 동의 날짜를 적는다.
