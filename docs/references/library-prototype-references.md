## 규칙

- **이미지·영상은 복사하지 않는다.** 게임 화면은 저작물이다. 무엇을 보고 어떤 원리를 가져왔는지만 적는다.
- **확인 수준을 적는다.** `직접 봄`은 이재엽이 보낸 화면·영상을 Claude가 열어 본 것, `검색 요약`은 검색 결과 요약만 본 것이다.
- 새 레퍼런스는 표에 한 줄 더한다: 무엇 / 가져온 원리 / 쓴 곳 / 확인 수준 / 날짜.

## 4. 시안 안의 "레퍼런스 서가"

시안의 레퍼런스 서가에 보이는 4개(EARS · MoSCoW · 실패하면 알리는 자동화 · 한 번에 하나만 묻는 화면)는 **더미 데이터**다(`books.js`의 `REFS`).
실제로는 사용자가 모은 링크와 한 줄만 저장하고, 본문은 열 때 원래 자리에서 가져온다(서재 설계 4절과 같은 규칙).
