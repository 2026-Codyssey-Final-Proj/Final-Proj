> **출처: 이재엽의 개인 프로젝트 "Alcovibe" 파일.** 팀 기준이 아니라 소개 자료다. 전체 소개: [README.md](README.md), 기능 목록: [features.md](features.md)

## 구조 한 장

Alcovibe는 이재엽이 쓰는 **개인 전체 환경**이고, 아래 프로젝트들이 그 안에서 같은 7단계 워크플로우를 탄다.
팀 저장소(Project Navigator)는 이 중 **세컨드 브레인**을 팀 제출물의 일부로 이어 가고 있다.

| 프로젝트 | 무엇 | 상태 | 팀 저장소에서 |
|---|---|---|---|
| **second-brain** | AI 시대에 내가 작업하는 모든 내용과 나만의 워크플로우를 담는 지식 창고. 마감 알림·점검·지식 쌓기 | 6단계 실사용 중 | **이미 있음** — `projects/second-brain/`(개인 정보를 걷어 낸 정제본), 기능 계획서는 이번에 가져옴 |
| **qa-prep-system** | 발표에서 받을 질문에 대비하는 시스템. 6슬롯으로 정리하고 꼬리 질문, 답변 카드 | 검증용 조각 1까지 | 스킬 `qa-prep`은 이미 있음. 문서는 [qa-prep-system/](qa-prep-system/README.md)로 가져옴 |
| **ai-os** | AI 운영체제 — 터미널에서 글로 지시하면 일감을 나눠 실행하는 "몸". 음성·생활 재료(일정·메일·알람 정리)는 그다음 | **시작 전, 재료만** | 가져오지 않음(팀 V2 결정: 지금은 `second-brain` 하나) |
| **alcovibe** (환경 자체) | 위 프로젝트·세션·요구를 한곳에서 보고 관리. 도서관 테마 제안 | 방향·초안 | 소개만([README.md](README.md)) |

## 팀 제품과의 관계

| 개인 프로젝트 | Project Navigator와 | 조심할 것 |
|---|---|---|
| second-brain | 팀 ADR-0006 제안: 별도 모듈로 두고 얇은 경계만(통합은 대회 후) | 새 기능은 11/1 기능 동결 이후 구현하지 않는다 |
| qa-prep-system | 발표 준비(11/9~11/11)의 예상 질문 카드에 쓸 수 있다 | 팀 제출물이 아니라 보조 도구 |
| ai-os | 직접 관계 없음. 판정·호출 경계 아이디어(ADR-0003)와 같은 방향의 규칙을 공유 | 대회 범위 밖 |

## 가져오지 않은 것

개인 세션 파일, 성장·접수 기록, `data`, 개인 계정·캘린더 연결 값. 이유는 팀 `CLAUDE.md`의 "V1 → V2에서 달라진 점" 표(개인 데이터는 이 레포에 두지 않는다)와 같다.
