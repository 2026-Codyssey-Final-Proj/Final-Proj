# 원작자 표기와 라이선스 기준 — 초안 (합의 전)

**상태: 제안.** 팀원 네 명이 각자 본인 줄에 동의하기 전까지 `LICENSE`·`NOTICE`를 만들지 않는다.
법적인 칸은 [legal.md](legal.md)에 모은다. 이 문서는 "누가 무엇을 만들었나"와 "그 기록을 어떻게 라이선스에 연결하나"만 다룬다.

## 1. 하려는 일 (이재엽 말씀, 2026-10-17)

- 프로토타입 제작에 도운 사람들을 문서에 **원작자**로 적는다.
- 그 표기를 **라이선스 기준**으로 삼아, 각자 자기가 작업한 내용을 쓸 수 있게 한다.
- 이재엽은 이 내용으로 창업·런칭을 해 볼 계획이고, 내년에도 이어 가며 대회에 나간다.
  (방향은 이미 [requirements.md](requirements.md) 8절 "소유·라이선스: 이재엽 + 팀원 동의 + 대회 규정"과 같다.)

## 2. 원작자 후보 표 — 근거는 TEAM.md와 커밋 기록

| 이름 | 역할 (TEAM.md) | 만든 것 (지금까지 확인된 것) | 표기 방식 (제안) | 본인 동의 |
|---|---|---|---|---|
| 이재엽 | 팀장·총괄·제출·AI 에이전트·API 연동 | 방향·요구사항·판정 규칙·기억 구조(`docs/00-overview/`, `projects/second-brain/`) | 원작자 · 총괄 | 확인 대기 |
| 고한결 | UI/UX·인터뷰·발표 흐름 | 화면 설계 문서, 마스코트 이미지 | 원작자 · 디자인 | 확인 대기 |
| 임유정 | 프론트엔드 | 시연 화면 초안, 구동 GIF 쪽 | 원작자 · 프론트엔드 | 확인 대기 |
| 두승현 | 테스트·검증·문서·협업 증빙 | 문서 취합, 시연 화면 이어받기 | 원작자 · 검증·문서 | 확인 대기 |

- "만든 것"은 **커밋·PR·이슈 기록으로 확인되는 것만** 적는다. 빠졌거나 틀린 곳은 본인이 고친다.
- 역할은 경계가 아니라 책임자다(TEAM.md). 한 사람이 두 칸에 걸친 일을 했으면 두 줄 다 적어도 된다.
- 임시 표기일 뿐 "누가 더 많이 했나"의 순위가 아니다. 협업 평가의 "균형 있는 기여"는 이슈·PR·리뷰 기록이 따로 보여 준다.

## 3. 원작자 표기를 라이선스에 잇는 방법 — 선택지

고르는 것은 팀이다. Claude는 종류를 추천하지 않는다.

| 방식 | 모양 | 장점 | 조심할 점 | 확인할 곳 |
|---|---|---|---|---|
| A. 이름 나열 저작권 표기 | `Copyright (c) 2026 이재엽, 고한결, 임유정, 두승현` + 허용 라이선스 | 각자가 저작권자로 보임 | 이름 공개에 각자 동의 필요. 나중에 한 명이 단독 상용화할 때 허용 범위를 [legal.md](legal.md)에서 확인 | 팀 전원 |
| B. 팀 이름 표기 | `Copyright (c) 2026 Project Navigator 팀` | 간단 | 팀이 법적 주체인지 불분명 | 전문가 확인 |
| C. 별도 `AUTHORS`(원작자 목록)와 `LICENSE` 분리 | 라이선스는 그대로, 원작자 목록은 `AUTHORS.md` | 목록을 나중에 고치기 쉽다 | 목록과 라이선스를 잇는 문장이 필요 | 팀 전원 |
| D. 파일(영역)별 저작권자 | 폴더별로 만든 사람 표기 | "각자 만든 것을 각자 쓴다"에 가장 가까움 | 공동 작업물(요구사항·UX 공유 문서)의 소유가 애매해짐 | 전문가 확인 |

"각자 작업한 내용을 사용할 수 있게"를 정확히 하려면 아래를 [legal.md](legal.md)의 해당 칸에서 정해야 한다.

1. 공동 작업물은 누구 소유인가(공동 소유 / 각자 기여분 소유 / 팀 소유).
2. **상업적 이용**(창업·유료 서비스)을 누가 할 수 있나 — 이재엽 단독, 각자 자유, 합의 필요.
3. 한 명이 상용화할 때 다른 원작자에게 **표기 의무**나 대가가 있나.

## 4. 반드시 같이 적을 것 (표기 문구 초안)

```
원작자(Original Authors)
- 이재엽 — 총괄, 방향, 판정 규칙·기억 구조
- 고한결 — UI/UX, 마스코트, 발표 흐름
- 임유정 — 프론트엔드
- 두승현 — 테스트·검증·문서

이 프로젝트는 위 사람들이 2026년 Codyssey Final-Project 기간(9월~11월)에 함께 만든 프로토타입에서 출발했다.
```

문구는 예시다. 이름 공개 여부와 영문 표기는 본인이 정한다.

| 1 | 이 초안과 [legal.md](legal.md)를 팀 이슈로 공유 | 이재엽 | 멘토링 1 이후 |

## 6. 이 문서가 하지 않는 것

- 라이선스 종류를 고르거나 권하지 않는다.
- 법적 효력을 판단하지 않는다.
- 팀원 동의 없이 이름·기여를 확정하지 않는다.
- 대회 규정을 확인했다고 쓰지 않는다 — 규정 확인은 아직 하지 않았다.
