# Project Navigator — 의도명세 캔버스

> 형식은 코딩마라톤 과제(Intent-Specify)의 12블록이다. **요구의 원천은 [requirements.md](requirements.md)이고, 이 캔버스는 그 의도를 한 장으로 보는 요약이다.** 어긋나면 requirements.md가 맞고 이 문서를 고친다.
> 시연 화면 안의 캔버스 형태는 별도이다(requirements.md 13-1, "캔버스는 화면과 문서 둘 다").

[개요]
AI로 바이브 코딩을 하는 사람이 프로그램을 끝까지 만들고, 이해하고, 배움을 쌓도록 **지금 몇 단계이고 어디까지 해야 하며 다음에 무엇을 할지** 안내하는 서비스.
프로그램을 직접 만들지 않고, 결정한 내용을 정리해 사용자가 쓰는 AI 코딩 도구로 넘긴다.

[미션]
"AI가 일하는 시대에도, 성장하는 건 사람이어야 한다."
결과를 대신 만들어 주는 AI가 아니라, 사용자가 작업 과정을 이해하고 **스스로 결정**하도록 돕는 AI 내비게이터가 된다.
프로그래밍을 배우지 않은 사람도 바이브 코딩을 끝까지 해낼 수 있게 한다(FR-13).

[핵심 활동]
작업 내용을 넣으면 현재 단계·완료 기준·다음 할 일 안내 (FR-1·2)
설계도(명세·계획·설계서) 초안 → 사용자 수정 → Claude 리뷰 (FR-3)
게이트마다 다이어그램으로 이해 확인, "아니요"면 질문·요약 계획서 (FR-4·5)
다음 할 일 정리와 우선순위 정하기 (FR-12)
진행·할 일·일정 충돌·토큰을 한곳에서 보기 (FR-6)
역량·노력 기록 쌓기와 역량 지도 (FR-8)
모르는 말을 그 자리에서 풀어 주기, 블록으로 이어 보이기 (FR-13)

[핵심 파트너]
코디세이 Final-Project 운영진·멘토 (멘토링 10/17, 10/31 제안)
Anthropic (Claude API)
사용자가 쓰는 AI 코딩 도구 (Claude Code, Cursor 등)
인터뷰 응답자 (이름·연락처는 레포에 올리지 않음)
교수님·대회에서 만난 사람들 (FR-11, 이름은 본인 동의 뒤)

[핵심 장벽]
"기존 AI API를 그대로 쓴 수준"으로 보이는 위험 (평가 기획 20점)
대상(프로그래밍을 배우지 않은 사람)의 문제가 실제로 있는지 아직 인터뷰로 확인하지 못함
토큰 사용량·Claude 작업 이벤트의 데이터원 미확인 (시연은 가상 숫자)
개인적인 말·행동이 팀에 보이는 공유 위험 (FR-9)
일정: 11/1 기능 동결, 11/8 18:00 제출, 팀장 한 명에게 몰린 일

[가치제안]
지금 어디이고 무엇을 해야 하는지 항상 한 줄로 보인다
이해했다고 답해야 다음 단계로 간다 — 넘어간 단계는 설명할 수 있다
결정은 사용자가 하고, 선택지는 장단점과 함께 보인다
결정의 이유가 기록되어 "왜 이렇게 만들었나요?"에 1분 안에 답할 수 있게 준비된다
배운 것이 역량 지도로 쌓여 다음 프로젝트의 조언이 된다

[부정적 영향]
개인적인 말과 행동이 같은 레포·이력에 섞여 다른 사람에게 보일 수 있음 (FR-9의 출발점)
안내를 따르기만 하고 스스로 판단하는 힘이 약해질 수 있음 [Claude 제안]
틀린 단계 판정·완료 기준을 자신 있게 안내할 위험 [Claude 제안]

[핵심 이네이블러]
Claude API — 게이트 판정 규칙·프롬프트·장기 기억(주력 둘 다, 확정 2026-10-14)
워크 프로세스 — 7단계에 코딩마라톤 루틴을 합친 하나의 개발 절차
게이트 규정 (DoR/DoD, Go·Recycle·Hold·Kill)
지식 창고 — V1 세컨드 브레인에서 일반화
공유 규칙 — 나만 보기 기본, 요약만/팀 전체, 재공유 금지 (`implementations/share-prototype`)

[핵심 데이터]
단계 기록·결정·이해 확인 결과
역량 레벨(처음 봄·이해함·직접 씀·응용함)과 노력 기록 — 항목·단위 미정
설계도(명세·계획·설계서)와 초안·수정본
공유본 (나만 / 요약만 / 팀 전체)
인터뷰 요약 (응답자 식별 정보 없음)

[혜택]
끝까지 완성하는 경험 — 막막함 때문에 중간에 멈추는 일이 줄어든다
스스로 결정하는 힘
설명할 수 있는 결과물
쌓이는 실력과 내 것으로 남는 기록

[비용]
API 호출비 — 측정 전이라 미정
인건비 — 팀 4인, 11/8 제출까지의 시간
서버·호스팅 — 시연은 서버 없이 가상 데이터로 하므로 없음
유료 도구 — 쓰지 않는다 (V1 기준)

[수익]
수익 모델은 정하지 않았다(미정). 대회 후 개인 작업으로 이어지며 소유·라이선스는 팀원 동의와 대회 규정 확인 전까지 미정이다.
기획안의 활용방안: 교육 현장(수강생 완주·이해도 확인), 취업 준비(포트폴리오), 협업 소통, 학교·직장
